# 毛巾机项目

预留的独立应用目录，基础平台为上级 ESP32-P4-WIFI6-Touch-LCD-3.5 工程，与用户确认的实物一致。

本阶段先完成唤醒和 AI 语音对话。后续依据实际电机、加热器、传感器、电源和机构定义 IO 与控制状态机；当前没有任何毛巾机执行器驱动。

起点已经具备：上级 `firmware/0.1.0-p4-3.5` 为读回验证过的语音固件，`hardware/native/ESP32-P4-WIFI6-Touch-LCD-3.5-Reference` 为可编辑嘉立创连接参考。原理图使用通用符号且封装待选，实际改板时先按上级 `hardware/README.md` 复核。后续应用代码和改板工程放在本目录，保留上级参考版本。
