## 开始测试

1. 关闭其它占用 COM5 的串口窗口，双击根目录 `开始语音测试.cmd`。
2. 说 **“你好，小言”**，听到提示音后说问题。支持普通话、粤语唤醒；本次回放检查为普通话／粤语／普通话各一轮。
3. 可以依次试“请用一句话介绍你自己”“请把四颗灯设为蓝色”“刚才是什么颜色”。测试较长问题时留意后半句有没有漏识别。
4. 串口中输入 `agent voice off` 停止自动语音；输入 `agent help` 查看命令。

USB 文字交互可双击 `打开设备对话.cmd`。重新安装使用 `安装最新版.cmd`，安装程序会先备份设备，仅更新应用区并校验数据区。

## 本版状态

- 当前源码的 C11 Agent、硬件工具、持久上下文、流式语音、提前准备回复和应答衔接已整理为固定构建配置。
- 沿用已有唤醒模型，没有追加训练；模型和静音状态已放入正式源码目录，编译不依赖实验材料目录。
- rc2 的控制任务状态查询支持本地等待；四轮工具调用用完后转入最终回答，保留实际执行结果。三次原录音复测均未再出现 `limit`。
- **未修复：模型仍会误报最终灯色。** 控制计划结束后恢复原输出，交付构建实测为 RGB 0,0,0，模型却说停在蓝色；中间一轮还输出过内部工具标记。完整保留这些回复失败，不算作全面验收。
- rc2 的 78 项主机功能回归通过，最终修改涉及的 4 项检查通过。rc1 的三轮唤醒及 USB 工具调用结果保留在其版本说明中。
- **仍是测试版**：误唤醒未修复，长句可能截断，一秒有效回复尚未达标，最低堆 46,572 B 低于原 48 KiB 目标。额外长问题测试保留失败，不作为全面验收通过。
- 使用设备现有联网和模型配置；本轮无需提供新安全密钥或申请额外安全权限。
