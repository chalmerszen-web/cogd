# Rev A 装配与首板上电

## 方向、接口与屏幕

PCB 坐标以顶面视图左上角为原点，设计毫米坐标 X 向右、Y 向下；立创原生制造坐标 X 向右、Y 向上，因此贴片文件 Y 为负数。不要人为镜像或把负 Y 取绝对值。所有元件 Layer=T，底面只作为贴屏面。

屏幕外形 34.70×46.75 mm，PCB 居中时每边名义缩进 0.20 mm。底面铺绝缘双面胶/绝缘垫，避开 FPC 根部和弯折区。屏幕厚度、胶厚和板厚累加后再确定外壳，不以示意图当作已完成的装配公差分析。

顶面看 J2 开口朝板下沿，连接器中心约 `(17.15,30.50)` mm；开锁运动包络已预留。LCD 原厂尾长 17.63±0.3 mm，接点厚度 0.30±0.05 mm。排线绕板下缘进入顶面上接点座，接触金属面需朝向座内弹片。设计据两张厂家图建立以下反序关系，**首次必须断电检查针序及贴合余量，先确认再锁座/粘屏**；不同尾部朝向的屏幕批次不能直接假定兼容。

## 装配规则

- C12、C13 为 RF π 匹配预留，首板 DNP；R7 为 0 Ω 初值，后续以 VNA/无线测试决定调整。
- TP1–TP6 是 PCB 铜测试点，不采购、不贴片；余下 101 个器件按 `ESP-HI-C3-RevA-BOM.csv` 实装。
- 未指定厂家料号的通用电阻/电容按 BOM 中的封装、阻值/容值、耐压、介质和精度采购。32.4 kΩ/10 kΩ 分压必须 0.1%；RF/晶振小电容用 C0G/NP0。
- 保留 `WS2812B-2020-V6` 和 `ESP32-C3FH4X` 的精确后缀；不能只按“2020 灯珠”或“ESP32-C3”替代。
- U1 裸焊盘接地，钢网为分窗；6 个散热通孔按普通盖油工艺评估吸锡，首件检查空洞/焊接。底面盖油不等于树脂填孔或铜帽封孔。
- USB 四个外壳焊脚全部顶面焊接，两个塑料定位柱不得顶到 LCD。标称 1.0 mm 板厚为此预留余量。
- 贴片坐标采用元件库旋转定义；首件装配前按交互 BOM 核对二极管、IC、LED 和连接器方向。当前 BOM 没有绑定某一家贴片工厂库存编码。

## 首板测试顺序（尚未执行）

1. 不插屏、麦克风和扬声器，测 VBUS/+3V4/+3V0_LCD 对地是否短路；核对 USB CC 电阻、U1 方向及 D2 二极管方向。
2. 用限流 5.0 V 台式电源供电，先检查静态电流和 3.392 V、3.0 V 轨；测启动/复位/负载瞬态，禁止以平均表读数替代峰值检查。
3. 确认 BOOT/RESET 下载、USB 枚举、40 MHz 晶振和测试程序；记录供电峰值与温升。
4. 断电插屏，确认反序针表和排线朝向，再以低速 SPI、空闲低电平启动屏幕。先跑纯色/像素定位图，再跑时钟，核对时分大字与右下角秒数。
5. 连接麦克风、扬声器，低音量起测；分开测 RGB、Wi-Fi，再测并发负载。四颗 LED 满白可达约 144 mA，Wi-Fi/音频叠加可能超过 USB 2.0 默认电流预算，固件需限制亮度/音量并实测。
6. 调谐射频和晶振，确认音频噪声、整机温升及机械贴合，再决定批量版本。

本次只交付 CAD 和样板加工文件，以上测试未执行；现有旧板时钟固件不能作为新屏的实物验收证据。
