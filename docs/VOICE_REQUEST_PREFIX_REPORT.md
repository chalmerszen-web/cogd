## 修改与验证

UX138保存的临时文字从“不用你”变成“你用一句话介绍你自己”。此前语法只支持
“请用一句话介绍…”等形式；通用话题检查将前置“你”计入内容，过早提名THINK。
本轮在介绍请求中接受可选“你／您”，同时从通用话题的开头剔除这类前导词。
单独的“你是谁”“你係邊個”仍保留原解析，最终对象仍必须完整匹配“自己／你自己”。

没有改写ASR或历史，没有放宽候选回复内容、最终输入、语言或捕获完整性检查。
附加人物、天文学等其他对象、否定、取消、改口、追加开灯以及新识别修订均覆盖拒绝路径。
普通主题仍可提名可撤销准备语。没有新增网络任务、音频缓存或VAD门槛调整。

`testfirst-01.log`记录原实现两项失败，`host-test-01.log`记录修复后12项全部通过
（ASan/UBSan开启，12.25秒）。包括实际临时文字重放、简繁体/称谓变体、原问题兼容、
候选线程生命周期、ASR片段与来源约束、流式管道及原结束检查。不是只修改最终字符串匹配。
