# 同连接最终意图工具续调：未通过

2026-09-27，UX48。目的是避免简单改口后总要转入完整DeepSeek流程。
本次仅验证协议，不改固件、不录音或播放、不执行任何硬件工具。

设计一个只读`await_final_input`：先在用户音频尚未发送完时请求模型准备，
随后用实际完整ASR及其输入编号作为工具结果，再在同一连接请求回答或
灯控提案。这样不需要假设服务端接受任意用户文本插入。
[官方客户端事件](https://help.aliyun.com/zh/model-studio/client-events)明确提供
原call_id的`function_call_output`及后续`response.create`，但文档支持并不
保证模型一定先调用所约定的准备工具。

预定只使用已有合成介绍、蓝灯、蓝改绿三段，发生失败立即停止。请求固定
在发送1.5秒音频后启动，输出协商16k PCM。一个付费会话目录最多一次连接，
不自动重试。灯控提案若出现只会返回未执行，不伪造成功。
