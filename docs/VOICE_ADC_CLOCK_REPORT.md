# ADC 采样时钟核对

UX526 已将精确时钟接入一次既有流式业务诊断：中/粤/中首次唤醒3/3、记忆任务3/3，严格输入2/3，SDK最低堆46396B未过原48KiB；未默认采用，原72已恢复。外部源与最后设备录音原波形门槛通过，原文字及资源失败保留；不作为误唤醒或一秒速度证明。见[三轮时钟集成报告](VOICE_CLOCK_DIALOGUE_REPORT.md)。

2026-10-04，UX514–517。ADC 取整偏差及其修正已通过设备采放核对；**没有证明误唤醒由这个偏差造成，也没有修好误唤醒**。时钟适配器默认关闭，未发布为当前测试固件。

当前本地 ESP-IDF 6.1 的 C3 ADC 连续采样 HAL 使用整数触发间隔。以其名义 APB 80 MHz、控制器分频 16、申请 32 kHz 和二分抗混叠为依据，间隔取整为 78，输出为 `625000/39 = 16025.64102564 Hz`，相对于标称 16 kHz 为 `625/624`。这是由 SDK 代码计算的名义值，不是直接读取运行中寄存器或测量晶振频率。

保存的全部 640 个块的设备时间戳作一次线性拟合，块周期为 31.948783 ms，估计输出率 16025.649456 Hz；与上述计算相差约 0.526 ppm，时间残差 P95 为 4.666 ms。时间戳发生在 DMA 数据被处理时，不能据此声称直接测出了 ADC 每个采样边缘。

只按事先由 SDK 推导的 `625/624` 比例产生一份诊断参考，并按同一比例换算相对播放时钟。没有按声音相关度选择比例，没有更换素材、搜索窗口或改变原波形／包络通过标准。

两份原始录音均未改变，原名义参考的全部分析值也重新复现。改进后的相关度属于单独的时钟诊断；不将 UX513 原失败覆盖成通过，不据此发布回复速度、双语唤醒率或误唤醒率。

初次基线检查将匹配器中的频段 tuple 与 JSON 的 list 直接比较，断言在计算新比例参考前失败。保存的叶节点数值完全相同，随后只修正 JSON 序列化归一化；初版脚本、清单和错误保留。没有更改任何数值门槛或挑选更好的比例。

本次耗时 0.312 秒，无模型前向、训练、云请求、采放或 Flash 写入。结束四项新鲜 USB 只读查询确认原 `0.11.72-summary`、空闲、wake/voice off；1385 个事件、940428 B、next4612、2 MiB 分区和 204800 B 历史预算保持，串口释放。证据在 `artifacts/voice-fast/wake-input-clock-ux514/`。

## C11 实现与同板校验（UX515–517）

新增默认 OFF 的 `AGENT_MIC_EXACT_CLOCK`。仅在 C3 音频构建启用；通过链接 wrapper 先调用 SDK 原配置，再于转换启动前将分频设为 `15, B39, A1`，保留原触发间隔 78。按名义 APB 80 MHz 计算，实际 ADC 为 32 kHz，现有二分抗混叠输出为 16 kHz。其他时钟源、频率或采样率不改写；麦克风启动读回不符即停止。新增 `agent mic clock` 查询配置与实际转换启停状态。

独立有理数公式、委托顺序、未知配置、复位／寄存器改动、JSON 边界的 C11 ASan/UBSan 测试通过。首次 C3 编译因 SDK HAL 头文件使用 `typeof` 失败，原日志保留；UX516 只增加该源文件的 `typeof=__typeof__` 兼容定义，继续使用 `-std=c11`，没有修改 SDK。实际 ELF 证实 wrapper 调用原 HAL，ADC 启动调用 wrapper 后才使能转换；状态为 4 B，无新增堆分配或任务。

诊断应用 `0.11.515-adc-clock` 为 1537872 B，正常预算剩 2224 B；SHA256 为 `96b6a7f3b36ae4a3541081aaa16a098d30b467a6e6ef3ff6671cc06be501a4a1`。基于冻结 UX471 配置、模型和分区构建，没有缩减上下文或任务栈。它是诊断候选，不是当前已采用版本。

UX517 只采一次 640 个实际关键词输入块，播放两遍原 3.68 秒音源，增益仍为 0.35。运行中读回 `15, A1, B39, interval78`、申请 32000 Hz、转换 active。序号／CRC／512 样本时钟完整，无 DMA 丢失、复位或满幅削波；640 次推理最大 14140 µs。

前置程序清单的相对路径错误和分析器 NumPy 布尔量 JSON 错误均保留初版与错误说明；只修正路径及标量序列化，没有重新采放或调整数值。安装和恢复均由 Flash guard 新鲜备份、校验、app-only 写入；整个 UX517 的上下文与录音分区逐字节保持。结束原 `0.11.72-summary`、wake/voice off、USB 释放。后续 UX518 原版阶段中止；UX519 单独候选 18 项仍有两条近词误触，UX520 又对普通话近词取得波形归因与全部 C 帧一致证据。时钟修正没有解决这些已确认误触，见 [实机误触对照](WAKE_CLOCK_PAIRED_REPORT.md)与[模型输入核对](WAKE_CLOCK_INPUT_REPORT.md)。
