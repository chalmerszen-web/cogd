# Development security properties

Wi-Fi password and DeepSeek Key are visible in the local configuration window by explicit user preference; `--hidden` is optional. The serial protocol, firmware status and diagnostic scripts do not echo those values. Provisioning clears its temporary copies and commits NVS only after validation. Existing NVS is never automatically erased on initialization errors.

Credentials remain development NVS data: secure boot/Flash encryption are not enabled, and physical Flash extraction can expose them. No eFuse operation is performed. Backups may contain old private configuration and stay outside Git. TLS private keys, test tokens, build products and local databases are also ignored.

DeepSeek uses a fixed HTTPS endpoint and the IDF certificate bundle. Gateway configuration must begin with https:// and uses its configured public CA. System time comes from SNTP or the trusted local provisioning/USB time command. Hostname verification is never disabled; redirect following is disabled. Network deadlines, one safe retry and a circuit limit repeated failures.

The static tool registry has 20 entries with M3 audio, 12 without. Wire names use the explicit underscore mapping. Unknown tools, duplicate call IDs, extra properties, invalid arguments and incomplete/truncated calls are rejected before execution. GPIO access additionally requires trusted board capabilities; the model cannot claim USB/Flash pins, enlarge budgets, execute generated C or access registers/shell/credentials. Plans are checked in full, including repeated-state prerequisites, before resource claims and effects. Status remains available while cleanup holds leases after a driver failure.

Legacy scores are bounded to 64 notes/30 seconds; independent M3 songs to 128 stored notes, 16 patterns, 32 sequence rows and 75 seconds. CRC/offset/length/UTF-8/timeout checks protect USB upload; uncommitted or cancelled input cannot start playback. The microphone is off at boot and enabled through USB or a requested tool operation. Level measurement alone discards waveform samples. Explicit capture stores one replaceable 0.1–10 second PCM clip in its separate local Flash partition; replay verifies CRC, processes the sound locally and does not modify source PCM. The clip is not uploaded or included in model context. Tool-result status may enter history. Captures/raw Flash backups and local analysis audio are private artifacts outside Git; there is no always-listening ASR service.

Logs contain conversation/test data and telemetry; treat them as private project artifacts. The Gateway is a local mock with a single development token, not a production authorization service. Never publish its state directory. Retention is bounded but preserves pending events and tombstones; changing user/session on a nonempty store is rejected.
