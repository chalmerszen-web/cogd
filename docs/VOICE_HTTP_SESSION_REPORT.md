## 改动与证据边界

原代码只为Vocalign保存HTTP TLS会话，DeepSeek跨轮重新连接。现在用一个由
网络worker持有的槽，分别识别固定服务来源；成功完整请求可保留SDK句柄最多
120秒，轮次结束关闭socket。更换服务、配置凭据、显式forget或到期清除状态；
使用中的请求遇到错误或未完整结束也销毁句柄。不复用公共签名下载，不跨轮
保留Gateway连接，不自动重放整轮请求，证书验证和禁止重定向保持不变。

`session_cached`仅表示选择了保留的SDK句柄；并不直接证明服务端接受TLS票据。
同一轮内也可能沿用仍打开的连接。跨轮关闭socket后实际connect耗时的变化另行
记录。保留句柄也会保留少量SDK内存，不能把“一个缓存槽”说成已经降低峰值RAM。
本机ESP-IDF源码的HTTP save_client_session和transport SSL SAVE/USE/FREE路径
为实现依据；其他芯片文档不是C3性能证据。

没有缩小2MiB上下文分区、200KiB发送预算或448KiB录音槽。语音专用提示词
精简措辞，仍保留用户语言、短句、TTS格式、工具与录音槽保留规则。
