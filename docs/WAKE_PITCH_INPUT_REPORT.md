# 设备录音的基频缺失诊断

2026-10-03，UX403–408。**现场误唤醒未修复，原395分类器仍不部署。** 本轮证明已有设备录音普遍缺少原基频前端可接受的周期证据；一个固定的两级低通原型没有改善它，因此已停止该滤波器，不进行全量特征提取、板上试验或训练。

## 排除句尾静音的影响

只读15791条基础TRAIN中6097条原正确唤醒的基频缓存。429条旧设备录音窗口里，触发前512ms有389条完全无可靠基频。改看原标注说话结束前512ms，仍有388条没有；277/429在整个4.096秒输入内都没有基频。

这是同源增强窗口，429不等于429个人或独立录音。原触发比标注结束的中位延迟为51.625ms；该结果不能只用“尾部包含静音”解释，也不能证明新模型失败一定由基频造成。没有新模型评分、阈值或标签调整。

## 一次固定低通实验

可选C11前端用16kHz、两级正系数一阶低通，名义1200Hz、betaQ15=12313、Q1状态。结果送到原 `pitch_fast`；原YIN的CMND、能量门槛、lag范围与40维logmel不变。INT32乘积最多1613864910，小于INT32_MAX，状态凸组合保持输入范围，不使用堆。

主机4096全范围极值/随机帧的1048576滤波样本及状态与独立INT64参考精确一致，630稳态频率帧满足原2%或2Hz范围，256白噪声、DC、静音、Nyquist、重置、实例隔离及ASan/UBSan通过。新结构780B，原770B；`block`有512B局部PCM，不是已证明的C3任务栈预算。原型不进入默认CMake或运行资源。

随后固定使用原44段TRAIN设备录音及其干净来源，共22正词、22负词；没有按新结果挑选素材。原归一化logmel450560值、原基频22528值、y、结束位置全部相同。干净来源按原采集lag/crop对齐，作为诊断参照，不当作真实基频标注。

| 固定指标 | 结果 | 原门槛 |
|---|---:|---|
|22正词声尾704帧的原 /滤后可靠基频|8 /7|必须增加，失败|
|滤后设备与源可比帧|48|至少64，失败|
|可比帧在源频率±20%内|44/48，91.67%|至少90%，通过|
|源基频被滤波保留|1215/1216，99.92%|至少98%，通过|

可比帧不是随机样本，91.67%不能推广为整个录音或现场音高精度。负词的有周期帧从22变18，只记录特征行为；它不表示误唤醒率，也没有调用分类器。实验2.316秒，程序exit0，但特征准入失败。原系数及滤波器停止，不换cutoff挑一版更好结果。

## 排除输入能量门槛

UX407按完全相同的原输入，只计算旧YIN用的8kHz窗口方差，并核对缓存有基频的帧均通过旧能量门槛。22正词声尾全部704帧已经达到门槛，只有8帧输出基频，其余696帧是未找到被原规则接受的周期。声尾各录音窗口的中位RMS再取中位约468.61 PCM单位，高于原门槛对应的约64。单纯降低能量门槛缺少证据支持。

本轮没有计算替代周期门槛、扫描候选滤波器、调整唤醒票数或重新训练。下一种方案应先检查这些未跨原CMND门槛的周期候选是否仍能与干净来源对应，再决定是否提供带不确定性的周期特征；不能直接把原所有零值替换为肯定基频，或把开发来源转成训练材料。
