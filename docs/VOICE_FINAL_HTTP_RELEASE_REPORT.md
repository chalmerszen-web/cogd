## 最小修改

新增默认OFF的AGENT_VOICE_HTTP_RELEASE。只给最终answer_end绑定新包装：HTTP producer已经返回后，由同一网络owner关闭已完成的HTTP连接，再join独立TTS任务；保留固定origin handle和session ticket。进度应答仍用原stream_end，feed/on_sent和中间工具请求不关闭。没有增加缓冲，也没有削减栈、音频缓存、TLS最大接收长度、2MiB上下文或204800B历史预算。

主机ON/OFF覆盖成功排空、取消/网络错误、失败启动、重复end及HTTP reader仍在使用时进度结束。成功TTS夹具必须等HTTP关闭才允许排空，能发现close-after-join回归；平台HTTP缓存、最终流式engine、deferred恢复及workspace所有权一同通过。真实ELF中的最终wrapper先call esp_agent_http_release，再进入stream_end，调用顺序核实。初始编辑把option位置指向根CMake的hunk失败，在任何编辑/构建/烧录前修正，原失败日志保留。
