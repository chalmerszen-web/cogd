## 数值与规则验证

C11 决策、64 对 INT16 极值和边界、ASan／UBSan、6144 块独立 Python 状态机一致；覆盖保护开关、稳定模式、采样时钟跳变、真实冷却、输出容量及空指针。决策器仍 24 字节，无新增决策状态；两个网络对的运行则另需约 6252 字节神经状态和少量平滑状态，不能把决策器大小当成整体资源结果。源代码确认现有 wake_cycle 在录音前调用 speech_disarm 释放模型，新方案未进行 C3 实测。

原 TRAIN 与实际输入复用 UX228 的分数，没有重训或再次推理；共 2017888 块 C 决策与独立 Python 完全一致。通过事先 TRAIN 准入后，才对固定 730 条开发验证语料进行一次双模型推理，747520 个 F64／FP32 双头值及 8 条 1085440 个 C 层值精确；730 条的 93440 块最终 C 决策也完全一致。TEST 未读，开发验证已被先前工作使用，不能称新盲测。

最小分数逐点不高于原分数，原整段冷启动负例没有事件时，新规则不会新增这个负例。冷却和票数重置会使事件时间／次数变化，不宣称每个新事件都是原事件的子集，也不据此证明连续环境的每小时误触率。
