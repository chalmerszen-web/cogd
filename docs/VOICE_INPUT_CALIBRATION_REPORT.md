# 当前语音链路输入时间标定（UX176）

2026-09-29 至 2026-09-30。目标是在真实边录音边上传 ASR 的条件下，测准播放源与板上采样的偏移，查明提前结束发生在完整输入前还是后。本次是有限诊断，不是用户感知速度或真人对话验收。

## 实测

三次单次唤醒：普通话、粤语、普通话。每次仅尝试一次；都得到已提交的 128000 样本／8 秒录音、400 个 20ms 元数据帧与 CRC 正确的追踪。无 DMA 丢失。设备沿用当前 Wi-Fi、Flash、实时 Qwen ASR 上传路径；候选连接可预热，但本诊断禁止候选提名，在 ASR 后立即退出。三次都返回完整改口“不要蓝色，改成绿色”，没有回复生成、语音播放、GPIO 工具或历史写入。

| 次数 | 唤醒读法 | 前标记位置 | 后标记位置 | 原结束判断 |
| --- | --- | ---: | ---: | ---: |
| 1 | 普通话 | 170 ms | 6540 ms | 3360 ms |
| 2 | 粤语 | 220 ms | 6590 ms | 3400 ms |
| 3 | 普通话 | 180 ms | 6540 ms | 3120 ms |

两枚不同方向的 160ms 扫频位于播放源固定采样位置。三频段相关度、竞争峰、偏移一致性和粗时钟间距均按试验前固定门槛通过 3/3。10ms 分析步长使时钟偏差估计只能用于检查明显漂移，不能当作晶振精度测量。对同一播放源以固定 10ms RMS 门槛取最后有效语音约在源语音段 5090ms；映射到板上约 5.72、5.77、5.73 秒。这个能量终点是代理标记，并非人工逐字语音真值。即便按该较早的代理点，原结束判断仍早约 2.36、2.37、2.61 秒。

结论是当前正常端点会在改口内容进入采集前结束，导致预测或最终回复缺少完整依据。完整 8 秒诊断证明后续内容在该硬件和并发上传条件下能被采到，也能被 ASR 识别；它没有证明 8 秒固定等待适合日常交互。先期推测可以继续用于提前建连与准备候选包，但任何动作和可听回复仍须由最终意图确认；中途改口必须撤销旧候选。下一步应在已测准的当前域录音上做有界续说判据验证，再在正常结束策略下进行连续三轮普通话／粤语对话与声学首响测量。

## 完整性与恢复

每次录音都单独暂停唤醒后从 USB 读回，录音与元数据没有补零，测试期间无工具/回复事件。上下文在试验前后均为 1187 条、845012 字节；2 MiB 分区及 204800 字节历史预算保持。此数与上轮旧快照不同，但进入本轮前已是该值；本轮前后相同，不能将先前变化归因于本次试验。两次 flash_guard 均先备份并验证整片 Flash，仅更新应用区，读回验证非应用区逐字节一致。

生产 407 份代码已逐文件恢复为 203 快照；正常固件 SHA256 为 `00be0038403e66183e69c167d01d565bc78f0173be96e88f157ffca27852314e`，无音频构建为 `90d399f9d7d3a05dc2f1c8f39b7142c8f1f2c6ef9483b9050f85158b4d8dffef`。设备已恢复 0.11.72-summary，联网监听、reuse 开、prefetch 关、DMA 丢失 0。当前仍未完成整项目标中的稳定低于 1 秒有效回答和三轮正常对话验收。
