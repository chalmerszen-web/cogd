# 原生近词分类训练：UX439–443

2026-10-03。**本次候选不合格，未烧录，现场误唤醒尚未修复。** 八类分类输出在 C 端保留的新架构虽然通过数值验证，但固定 TRAIN 材料中的词语区分效果不及上一版已被拒绝的单输出模型。本配方停止，不做第二次训练、阈值扫描或根据开发／测试集选择参数。

## 改动及验证范围

新增 `training/kws/native_phrase.py`，在已有 90 输入、24 通道因果骨干上保留 24→8 的 C11 整数类别投影。目标词分数直接使用“小言”类别与最强近词类别之差；原标量末层冻结，只保留 ABI，不用于决策。

训练首 11 层的 9,960 个整数权重和类别头 192 个整数权重，共 10,152 个可训练系数。偏置、shift、归一化、原 PCM、标签、抽样及 6,146 个正锚点保持；不使用 BN 或训练后量化。原四项事件／锚点／前缀／撤销损失之外，加固定短语尾部 mask 的类别平衡 CE，权重 1。

旧 UX429 被拒绝模型只作为初始权重来源，不能据此宣称它可部署。新类别头固定小整数成对零和初始化，偏置 0、shift 5，未选择初始化或尺度。旧单输出及导出删除辅助头的配方保持停止。

UX439 在语义训练前检查初始及模拟更新两种权重：2,244,608 个完整层、类别及差值的 C／FP32／F64 值完全一致；类别平衡损失、忽略帧零梯度、共享骨干梯度、padding mask 和 7 个 checkpoint 拒绝检查通过。35 条完整因果输入的前向／反向中位耗时为 37.84 ms，这是电脑成本，不是 C3 推理时间。
