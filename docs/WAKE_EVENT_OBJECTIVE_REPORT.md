# 事件目标训练与归一化差异诊断

2026-10-02，UX266–268。**误唤醒尚未修好；新模型未通过完整准入，未烧录。** 设备核对为原 `0.11.72-summary`，自动唤醒和语音关闭，USB 文本可用。

UX265 已证明浮点训练结果本身有识别退步，量化不能解释主要损失。本次先审计目标，再实现与设备判定一致的损失，只训练一次新候选；失败后只读检查 BN 差异。

## 目标审计和实现

全部 15791 个 TRAIN 窗口中，没有发现完全相同输入却标签相反的窗口；这不能排除更短上下文的歧义。原接受区间内的高分块中，普通话 3542/18410、粤语 2806/13460 的逐帧标签为 0。这里统计的是三块均值后的判定分数，不能把每个块都当作必需的原始神经头。

补充检查原始平均神经头，高分但标签 0 的对应数量为普通话 1125/19461、粤语 931/14039，约 6%。标签差异是目标对齐线索，不是单独的根因证明。新浮点的 183 条普通话损失中，24 条存在足够的接受区间机会却无接受事件；213 条粤语损失中对应 67 条，提示提前触发/冷却与事件时刻也需监督。

新增主机模块 `training/kws/event_loss.py`。前向执行 signed Q8 round-away、INT16 限幅、原三块向零均值和三块中值；中值超过阈值恰好对应 twoof3。梯度通过 straight-through 近似，设备没有增加 PyTorch 或浮点运行时。

允许端点的机会用 `268/256+1` 的平方 hinge，禁止端点用 `268/256-1` 的平方 hinge，另加 0.25 倍剔除冲突标签的逐帧 BCE。禁止区间包括提前与过晚机会，正父源在本地窗口没有允许端点时按负窗口处理；无效尾和预热区不参与。实际判定的阈值、冷却、预热及接受容差保持不变。

测试通过 4096 个随机/极值分数与实际 C 事件、因果前缀、梯度、预热历史、尾掩码、无本地正端点及错误形状拒绝。第一次单测有 `Tensor.fill` 拼写错误，保留失败后修为 `fill_` 并重验，没有重新运行质量实验。

## 唯一候选结果

从固定新 seed `2026100267` 初始化 48 通道，CPU 四线程，4000 步、batch32、一次 final-only；未继续失败 checkpoint。复用 17066 个完整覆盖窗口。旧负例各见 3–4 次，普通话 7–8 次，粤语 10–11 次；实际正窗口 102–103 次，实际负窗 24–25 次，自然窗 16–17 次。84 个正父源窗口没有本地允许端点，明确处理，未错误地要求其唤醒。

训练 84.90 秒，含既定 TRAIN512 PTQ 共 87.27 秒。没有网格、中间模型选择、追加拟合、DEV 或独立 TEST。

## BN 差异的只读检查

固定四个平衡 32 条批次，包含首次 32 条旧普通话损失、32 条粤语损失、32 条新增负例触发和32条干净控制。用相同权重比较冻结 evalBN 与临时 trainBN，耗时 0.17 秒，没有优化器或参数更新。

| 诊断 case | 冻结 BN 正确 | 批统计 BN 正确 |
|---|---:|---:|
| 普通话损失32条 | 9 | 18 |
| 粤语损失32条 | 6 | 17 |
| 新增误触32条 | 0 | 0 |
| 干净控制32条 | 32 | 27 |

这是选择过的已知失败 case，不能作为准确率。trainBN 使用整段未来及同批其他输入统计，不满足设备因果流式约束，禁止作为固件方案。BN 差异影响部分漏醒，同时破坏控制项，且没有清除这32条误触；单独更改运行均值不能据此认定为修复。临时 BN 缓冲丢弃，原 checkpoint、权重及冻结状态保持。

源码、配置、种子、覆盖计数、接受元数据、checkpoint、C/JSON 模型、分数、事件与 BN 诊断分别保留在 `wake-event-objective-ux266/`、`wake-event-fit-ux267/`、`wake-bn-gap-ux268/`；267 的源码归档覆盖这三阶段。模型 C SHA256：`bf2ad4b29d0bfd09e13f51c7cf390968d26ee022ac50f1a05e152af8f0c40193`。

没有 Flash、云调用或新声音采集。结束时 USB 实查原72/off/off；历史、2 MiB 上下文、204800 字节历史预算、4824 ms 录音、音量80、灯及摘要保持，USB 已释放。完整语音业务目标仍未完成，不把这些主机结果代替三轮连续实际对话和连接峰值资源验收。
