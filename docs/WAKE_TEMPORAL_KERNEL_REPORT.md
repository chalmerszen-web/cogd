## C3 资源实测

UX218 使用冻结的当前 `0.11.222-wake-gate` Agent，包含此前的录音错误归属、流式传输和保护期决策修正。在私有工程增加默认关闭的诊断入口，版本为 `0.11.223-temporal-budget`；没有改动 root 固件代码或设备分区。

先以同一份 USB bench 源码执行主机 ASan／UBSan，检查会话启停、空指针、CRC、顺序拒绝及版本化报表。主机计时、堆和栈是明确的假值，仅数值校验是真实结果。随后在 C3 执行原模型、6960 个零系数、仅逐点交互、同逐点系数加时序交互四阶段，每阶段 256 个 512 样本块，总计 1024 块固定合成输入。没有麦克风采集、扬声器播放、云调用或优化器更新。

| C3 阶段 | 每个 32 ms 输入块的最长计算时间 | 数值 CRC |
|---|---:|---:|
| 原 E/L 网络 | 10.969 ms | 1482158500 |
| 新内核，全部交互系数为零 | 11.509 ms | 1482158500 |
| 仅逐点交互 | 11.738 ms | 2101441176 |
| 逐点＋时序交互 | 11.548 ms | 1617045471 |

计算时间覆盖两次完整的 256 样本前端、网络及融合，排除输入生成、完整 CRC 和任务让出。CRC 覆盖两支各 265 个层值、前端、分数、事件和所有 6252 个神经历史字节，全部与主机相同。第二支 trace 借用既有 `first.trace`，没有另建缓冲；正常无外部 trace 的调用保持原行为。零系数与原模型精确一致。

会话工作区为 12632 字节，神经历史仍为 6252 字节。采样最低空闲堆 85076 字节，会话结束后的全局最低堆记录为 83064 字节，均高于 48 KiB。USB 任务实测剩余栈为 1564 字节，高于冻结的 1024 字节门槛。会话已释放，没有观测到意外复位或 DMA 丢样。这些是合成资源测试，**没有验证完整语音业务的峰值内存、连续人声或现场误触率**。

单个模型需要 6960 字节交互权重；资源诊断包含三组未训练的只读系数，共 20880 字节。最终诊断应用为 1526112 字节，在正常 1540096 字节预算内余 13984 字节，原应用槽仍余 46752 字节，没有借用诊断预算或缩减上下文。`size.json` 的 1525964 是链接 section 总和，应与 BIN 大小区分。

构建时发现历史冻结归档漏掉 managed components、YAML 依赖清单和后加的 TEN／RV 源码。已补入原锁定版本的 554＋2＋33 个文件，并检查 43 个固定 VAD／RV／自有源文件 SHA。保留三次配置失败和头文件路径、C11 SDK `asm` 兼容问题的编译失败记录；只修复工程材料和适配宏，没有改数值实现、模型或预算。最终匹配源码归档包含 1055 个项目与依赖文件。

一次 `idf.py size` 调用默认启用 ccache，意外开始重编译；已在链接前终止该调用自己的进程树。冻结应用、ELF 和 map 仍逐字节一致，最终用 `esp_idf_size --format json2` 直接读取保留的 map，避免再触发构建。报表初始固定文件计数及编码拼写错误也已修正，没有重复上板或选择另一映像。

安装和恢复均通过 `flash_guard.py`，分别完整备份并校验 4 MiB Flash，只更新应用、读回校验，所有非应用字节相同。设备已恢复精确的 `0.11.72-summary`，自动唤醒与语音关闭；1254 事件、879268 字节、下一序号 4481、2 MiB 上下文分区、204800 字节历史预算、音量及灯状态均保留，USB 已释放。
