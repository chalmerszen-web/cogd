## 实现

隔离ASR分段更新增加`confirmed_bytes`，标明现有UTF-8文本缓冲中连续确认前缀
的边界。解析器在原有partial/segment通知前同步发送`asr_prefix`：回调期间临时
在边界放置结束符，返回后恢复原字节，再通知完整预览。没有第二份转写缓冲
或新动态分配，候选准备仍收到原来的完整预览。

同一预览从草稿提升为确认文字时仍发通知。后段final先到、前段final缺失时，
不能把后段文字标成连续前缀；空final、新段和取消继续清除或修订相应视图。
主机更新结构从12B变为16B，持久会话及分段状态结构不变。新增通知的并发栈
水位和USB开销尚未在板上测量，不据源码大小宣称运行内存验收通过。

确认前缀不保证识别正确，也不代表整条命令已结束。本轮不改变ASR辅助准入、
VAD阈值、停录时间、候选释放或GPIO执行条件。Omni原有路径也未改成新策略。
