# UX119：在模型生成期间提前连接正式语音输出

2026-09-28，实验版本 `0.11.157`。六轮实机对话都成功接管提前建立的TTS连接，
接管耗时0–1ms。**这是连接时序的改善，尚未达到稳定一秒回复，未推广实验固件。**

## 修改及边界

用户提出边听边预测、异步准备回复。本项目此前已在部分意图上实现临时转写触发备答，
最终输入通过校验后才放行音频；改口、取消和不一致会撤销候选。本阶段进一步处理
完整Agent回答的串行等待：156保存的三轮正式TTS连接耗时952/1203/959ms，位于模型处理之后。

157在第一份DeepSeek规划请求体发完后，使用原有primary连接槽预建TTS WSS。
云端模型可以在此期间生成，已有的准备语也可以继续播放。此时只建立连接，
不发run-task、不发文本、不生成PCM、不占扬声器、不借用Agent工作区。
正式TTS开始时才提交独立task_id，等待task-started，再发送真实答案。
[官方WebSocket协议](https://help.aliyun.com/zh/model-studio/cosyvoice-websocket-api/)
区分建连、启动任务与发送文本；本地10秒接管期限不是服务端空闲时长的保证。

引擎新增可选的准备回调，每轮最多调用一次；不改变规划提示词、工具策略、输入权限和历史。
连接准备仍在现有网络任务中同步执行，因此可能推迟本地读取模型响应或执行工具。
它重叠的是远端计算与建连，并非新增并行网络线程；不能把全部握手时间直接算作总延迟收益。

未使用的预连接在每个退出路径清理；过期、取消或配置变化不能被接管。
10秒期限在接管或清理时检查，并非独立定时器保证恰在10秒释放内存。
接管后沿用现有TTS生命周期；预连接清理不能关闭已经接管的任务或独立ASR连接。
预连接失败且未取消时允许后来正常建连，因为尚未提交语音任务；不重放已提交的任务或声音。
准备回调的错误也不能触发规划HTTP重放。

没有新增任务、大块缓冲或关键字规则，没有缩减上下文。新增8B连接期限状态及小型引擎字段。
候选工作区仍16576B。ASR/VAD、音量、模型和分区保持原设置。
