# 完整音节序列原型，尚未修复误唤醒

2026-10-03，UX446。新增隔离的 C11 序列解码原型，完成逻辑与对象资源检查。**没有训练声学模型，没有加入固件编译列表，没有烧录，也没有新的声音识别成绩。** 当前设备仍使用原唤醒方案；既有被拒绝的模型和门槛实验保持停止。

已有同板对照中，原版接受了两条“你好小燕”，负例为 2/10；这个小组不能换算日常每小时误唤醒率。提高阈值、固定延长确认及此前多次模型训练没有通过原准入要求，详见[同板误唤醒对照](WAKE_LATEST_COMPARISON_REPORT.md)。播放及录音期间已有暂停检测的代码保护，但代码检查不能证明现场每次误触发的声源。

## 新原型的输入合同

未来声学模型须每 512 个 PCM 样本输出 14 个 `int16_t` 音节类别分数。普通话路径为 `NI → HAO → XIAO → YAN2`；粤语为 `NEI → HOU → SIU → JIN4`。前缀类别需要学习实际读音变体；最后音节区分目标词和“燕”的其他声调。另有 blank、other 及明确的非目标词尾类。

原型采用 [CTC 的重复标签和 blank 折叠规则](https://www.cs.toronto.edu/~graves/icml_2006.pdf)，再做两个固定完整词序的后缀匹配。它是 greedy 解码，不是 CTC 概率求和或 beam search；CTC 论文不提供本项目的训练权重，也不证明当前 C3 的声学效果。

只有唯一最大分数的类别可以推进序列；并列最大值清除匹配证据。四个音节齐全后需两个 blank 输出帧才提交事件。blank 是训练模型的类别，不等于要求用户停止发声 64 ms。整个音节路径最多跨 48000 个样本；不完整片段、错序、跨语言拼接、错误词尾、时钟断续、禁用检测及无效输入都不能复用旧证据。

当前两个 scalar 唤醒网络不能输出这个类别接口，不得将它们的分数转换成伪音节来接入。真实模型的声调辨别、blank 对齐、连读召回和延迟仍须训练及实测。神经网络预热、事件冷却、ASR 和录音所有权仍属于原调用方，本原型没有替换这些行为。
