# UX127：云端定稿主导停录的有限实验，已撤回

2026-09-28。本轮测试“候选回复的流式采集，只能由经过校验的ASR定稿结束”这项假设。
**实机出现明显回归，未采用。** 异步预备答案、完整意图校验、改口撤销的既有实现保留；
此次停录策略从当前源码撤回，设备恢复`0.11.72-summary`联网监听，没有更新默认安装包。

实验版本166保持严格的本地起音校验，将该流式路径的本地静音结束改为等待可撤销的
云端结束提议。保留160ms源音频覆盖及160ms定稿观察、新续说撤销、未完成参数的有界
等待、10秒音频上限和取消；不再叠加通用句间等待。生产者不再用能量静音提前停止
这条路径的采样。旧经典路径、ASR服务参数、音量、输入容量、历史预算和分区均未改。

66/66主机ASan/UBSan检查通过，34.43秒，覆盖无定稿、撤销、续说、取消、硬上限，
以及10秒真实源帧覆盖。归档版本的轨迹解码器3项测试通过。六段既有八秒实录用原始
源时钟提示重放，旧行为6/6一致；新行为一段在7720ms结束，另五段到保存材料末尾
仍没有可接受的结束。后五段记为未知，没有补造后续音频，也没有计作速度成绩。

随后只做了预先规定的两组三轮实机实验：增益0.25、capture预建连、prefetch/reuse开启，
各组依次普通话/粤语/普通话唤醒，业务输入均为普通话合成素材。失败没有重跑刷分。

第一组第一轮识别成“嗯。把灯调成蓝色，不对。要来改一改。”，设备追问颜色，灯读回为关。
第二轮超时，灯仍关。第三轮识别为“调成蓝色不对。不要蓝色，改成绿色。”，灯读回
`(0,255,0)`并确认绿色。第三轮关键条件正确，但缺失开头文字，保守的完整输入检查未通过。
不能将1/3正确动作写成完整交互验收通过，也不能由这三个样本推算识别率提升。

第三轮导出的真实录音为126592样本、7.912秒，SHA256：
`505b03d71b69362885737e5c43e46c39fb173dff6d42256c1e3de1f4b249138a`。

因此仍不能宣称采集质量或全部词语保真通过。原音频及两套原始识别结果均保留。

短问候前两轮分别在采集开始后4727/4510ms收到完整的`asr_segment_final`文字，

“只要等待定稿就会正常结束”的假设；本次普通运行没有逐帧轨迹，究竟是源覆盖、
时间戳、新分段撤销还是本地续说门槛拒绝，尚不能确定，不能直接归因为麦克风噪声。
