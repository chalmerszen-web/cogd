# P4 设备内循环日志

用于脱离电脑进行压力测试后，经 USB 取回最近运行记录。实现版本：
`0.10.2-p4-aoq-log`；当前语音修复候选为 `0.10.9-p4-noise-tail`，
日志实现不变。这是运行日志，不是完整 CPU 内存转储。

## 使用

接好 USB 后，可双击项目根目录的 `导出P4运行日志.cmd`。完整导出约需数分钟，
期间保持 USB 连接。

在项目目录使用随项目安装的 Python：

```powershell
.toolchains/tools/python_env/idf6.1_py3.11_env/Scripts/python.exe -X utf8 tools/p4_logs.py on
.toolchains/tools/python_env/idf6.1_py3.11_env/Scripts/python.exe -X utf8 tools/p4_logs.py status
.toolchains/tools/python_env/idf6.1_py3.11_env/Scripts/python.exe -X utf8 tools/p4_logs.py export
```

默认端口 COM3，可用 `--port` 指定。开关保存在设备里，重新启动后继续生效。
关闭用 `off`，不会删除已有日志。可用 `mark --text 测试开始` 放入测试标记。
导出到 `.local/p4-logs/日期时间/`：

- `runtime.log`：可直接阅读的时间线。
- `events.jsonl`：按启动编号和时间排列的事件。
- `manifest.json`：设备信息、页序号、校验值、丢弃和截断计数。
- `pages/`：原始页，逐页验证 CRC 和提交标志。
- `usb/`：此次 USB 读取的原始记录。

导出期间暂停记录，完成或遇到异常后工具会尝试恢复；若工具中断，设备在
10 分钟后自动解除导出暂停。存储写入故障导致的暂停不会自动解除。
使用 `--last-pages 24` 可以只取最近约一分钟。导出不触发设备重启。

## 记录范围和保留时间

- SDK 日志、语音流程事件、约每 2.5 秒一次的内存和采音健康状态。
- 采音累计帧数、最大处理耗时、超过 32 毫秒的次数、接收溢出次数。
- 启动编号、重启原因、固件版本、ELF SHA-256。
- 每条记录含开机时间；网络校时后也可映射到电脑本地日期时间。
- 1 MiB、256 个 4 KiB 页。正常连续运行按约 2.5 秒一页轮转，覆盖约
  10 分 40 秒；写入耗时会使实际时间稍长。主动反复冻结/开关会额外提交页。
- 单条最多 704 字节。每批超过容量时丢弃新记录；页头公开累计丢弃和截断
  数量，不能将导出文件当作无损的全部输出。包含已知凭据标记或
  `data:image/`、`data:audio/` 前缀的记录会被省略。
- 突然卡死、复位或断电时，当前尚未提交的一批可能丢失；通常约为最后
  2.5 秒，调度严重受阻时可能更长。已提交页独立校验；不完整页被跳过。
- 未接 USB 时照常保存。彻底卡死时需要先重启才能导出；应尽快取回，
  以免后续正常运行覆盖故障前窗口。早于启用此功能的故障无法补录。

## 存储和实时路径

不更改分区表。`media` 最后 1 MiB（绝对地址 `0xF00000..0xFFFFFF`）
专用于日志；字体、对话存储和录音分区不变。视频缓存上限相应减少 1 MiB，
新的写入、擦除和旧缓存加载检查都使用同一上限。回退到不识别这一区域的
旧固件后，媒体缓存操作可能覆盖日志，因此回退前应先导出。

日志生产者只做有界内存复制，不等待 Flash；低优先级任务分批写入。
写入最大耗时、存储错误、丢弃量可由 `agent log status` 查询。
页 CRC、提交标志最后写入，避免将掉电中断的页误认为完整记录。

中文字库启动时读入外部内存，避免常驻 Flash 映射让 SDK 在每次日志写入时
暂停缓存访问；额外占用约 1.29 MiB 外部内存。字库数据和字体加载接口不变。
本模式用于诊断和压力测试；测试完成后可关闭，减少持续 Flash 擦写。

原始 USB 接口：`agent log on|off|status|freeze|resume`、
`agent log mark TEXT`、`agent log read SEQUENCE OFFSET COUNT`。
读取单次最多 256 字节；建议使用上述工具完成校验和导出。
