# 条件唤醒后端的静音初始状态恢复

2026-10-03。新增可选C11模块，正常固件未采用，未烧录。

此前UX332新后端的64块零PCM初始化实测730720微秒。新模块从完全相同模型、前端及负证据撤销控制器的真实计算导出类型化Flash状态，恢复三支神经历史、判定、滤波与虚拟32768采样时钟。FFT临时工作区不持久保存，前一帧PCM经导出器确认全零；调用者必须是相同三模型的默认新初始化。恢复后继续沿用虚拟时钟，避免首帧被当作时钟跳变。它不会降低原阈值、warm、冷却或业务预算。

实现为 `prototypes/kws_conditioned_seed/kws_conditioned_seed.c`、头文件及主机导出/合同程序。构建消费方必须冻结模型、算法和生成include哈希；任何改变都要重新生成和验收。当前只编译目标对象，尚未接入实际应用。

第一次数值合同UX359通过，4.369秒：真实64块静音与恢复后的2048帧PCM逐值一致，包含1998 armed帧、7gap、完整神经/控制状态、logmel、原始输入、原/辅助trace、头、滤波和事件。共1249280 trace值，ASan/UBSan没有报错。四种非空拒绝（阈值、错误模型、稳定模式、重复恢复）保持原状态，NULL拒绝；专门核对warm后已取得支持被负证据撤销。随机PCM中两路径都没有检测事件，不能把该随机合同称正词识别测试。
