# 声学权重可训练原型（UX232，2026-10-01）

**整网权重训练的整数导出链已经验证；没有训练或识别成绩，误唤醒仍未修复。**

UX230 剩下三条近似词在两个模型中均为高分。此前交互训练固定了原声学权重，本原型允许 12768 个原声学 INT8 权重参与梯度，加上 6960 个交互系数，共 19728 参数、26 个张量；bias、shift、归一化、通道/层/时序均固定。复用已验证的 C11 参数接口和时序内核，没有通用模型运行库。神经状态仍为 6252 字节，工作区结构不增加；这是结构推断，未做新权重实机资源测试。

选择在运行前固定：TRAIN 中粤正负各首 4 条（16 条），actual 中粤正负各首 1 条（4 条），另 5 个零/极值/随机/冲激输入。共 25 流、7424 帧，没有读开发验证或 TEST，也没有评分识别率。

三种控制：初始原权重＋零交互、固定整数扰动、正负半整数参数舍入边界。每种 3934720 个层值在 F64 直接卷积参考、FP32 带梯度模型和 C 环形实现中完全一致，合计 11804160 个层值。26 个训练张量都有有限非零梯度，固定 buffers 不变；最大保守部分和 1977039，小于 FP32 精确整数边界 2^24。

首轮比较失败来自测试夹具把 C 的“分支/时间/层值”与参考的“分支/层值/时间”直接比较；轴对齐后，原 literal 和重新导出 C 模型数据都零差异、ABI 字段零差异。首轮及诊断日志保留，没有改变数值、权重方案、模型选择或识别门槛。额外半整数检查针对训练时参数将成为浮点数这一实际风险，不是新识别候选。

下一步只允许另行声明的一次有时限拟合，从原 E/L 权重及零交互开始；本次扰动权重不是候选，不能烧录。训练后必须导出所有声学权重和交互，先通过 TRAIN/实际数值与识别保留条件，才进入开发对照。若整网/非零交互用于设备，需要针对新权重、交互和 C 内核重新生成带 hash 绑定的完整静音状态，旧普通 E/L 静音缓存不能直接复用。
