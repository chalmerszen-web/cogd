# 已标定实录的冻结语音模型检验（UX177）

2026-09-30。用 UX176 三份当前 ESP-HI 边采集边上传 ASR 的完整板上录音，离线检验 UX175 已冻结且未通过旧验证的 1313 参数小模型。保持原 0.5 判据、C 定点 40 频带前端和权重，没有再训练或择优调整。

| 来源 | 语音代理命中 | 尾部背景代理被接纳 | 原结束点后达到四个强帧的时间 |
| --- | ---: | ---: | ---: |
| 普通话 1 | 99/132 | 34/69 | +520 ms |
| 粤语 2 | 96/136 | 41/66 | +540 ms |
| 普通话 3 | 102/139 | 45/69 | +760 ms |

总体语音代理 297/407＝73.0%，背景代理 120/204＝58.8%。预先固定的进入后续门槛为语音≥90%、背景≤5%；两项明显失败，因此**不集成该模型**。三次标记同步声及前后 200ms 被排除；标签来自原 TTS 播放源的稳定 32ms 能量，不是真人人工标注，也不能据此计算每小时误唤醒。

逐帧硬件元数据给出另一个有用线索：原终点 3360/3400/3120ms 后，设备在 3760/3800/3740ms 再次看到超过原噪声门槛的频谱强帧；在原终点之后 520/540/760ms 累积达到四个强帧。三份后续 3.6–5.8 秒片段分别有 32/35/30 个此类强帧，6.9–8 秒背景尾段只有 1/4/0 个。这个现象说明改口并非完全低于原始声学判据；主要是现有端点过早锁定终态。单纯把结束延后 800ms 尚未经过完整 C 状态机和短句/噪声压力测试，不据此改固件或承诺一秒响应。

推测机制的下一步应把早期结束作为可撤销的候选边界：在等待短暂续说证据时预取答案，但 GPIO 和可听的具体回答只由最终完整 ASR 授权。独立回放需要证明发现后续四个强帧能撤销候选，也必须检查简单短句的额外等待、背景误触发和取消；失败就维持现有发布版。冻结小模型在当前域的背景误接纳太高，不能承担这项决策。

三份录音都是同一个 TTS 原声的回放，跨语言的行名指唤醒读法，不代表改口内容有三种独立说话人。所有逐帧分数、标签和原 C 前端输出位于 `artifacts/voice-fast/calibrated-vad-ux177/features/`；总表为 `inference.json`，原元数据检查为 `frame-inspection.json`。无新云请求、采集、训练、端侧运行或烧录。407 生产文件、正常与无音频二进制 SHA 均仍为 UX176 恢复态；设备状态以 UX176 恢复实测为准，本轮没有重新查询设备。完整目标与正常连续三轮验收仍未完成。
