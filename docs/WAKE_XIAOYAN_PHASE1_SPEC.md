# 小言 Phase 1：计算与资源样机

本阶段接入现有完整 Agent，只使用固定种子 20260921 的非零、未训练权重。
`trained=false` 在核心输出处屏蔽实际唤醒；不能把本阶段结果作为识别率。
现有 WakeNet 源码及 0.6.3 回滚包保留，构建开关 `AGENT_KWS_C11` 默认关闭。

## 冻结的计算契约

16 kHz PCM16 单声道，输入块 512 样本；内部每 256 样本运行一次。
512 点对称 Hann Q15、KISS FFT 131.1.0 Q15（每级缩放，总体约 1/512）、
125–7500 Hz 的 40 个连续三角 Mel 滤波器，权重 Q15，非负能量累加使用 uint64。
能量右移 15 位并就近取整、钳位 uint32，再以 256 项分数查表求 log2 Q8.8。
固定每带均值 Q8.8 和逆标准差 Q12；相乘右移 15 位，得到 scale=2^-5 的 INT8。
探针均值为 12、标准差为 4；这些是测试参数，训练前必须仅用训练集估计。
Hann/FFT/Mel/log 表由 `training/kws/export_c.py` 冻结，SHA 记录于 generated/manifest.json。
KISS 自身沿用其 Q15 舍入；前端窗口、归一化和网络使用正负对称、半值远离零舍入。

网络：40→24 的 kernel=3 因果卷积；五组 DW(kernel=5,dilation=1/2/4/8/16)
加 PW(24→24)；最后 24→1。BN/ReLU 只放在 stem 和各 PW 后，DW 后无激活。
不含残差、池化或 softmax。权重 6384 个；训练参数 6673 个；折叠权重和非零可存储
bias 共 6964 B（不含元数据和缩放表）；历史缓存 3056 B；每块 12768 MAC。
声学感受野 2048 ms。C 环形缓存与 Python 直接时间索引分别实现，用于交叉比对。

INT8 对称量化，零点 0；权重每输出通道、激活每层使用 2 的整数次幂缩放。
累加 int32，右移半值远离零，左移用 int64 乘法并饱和，不对负数做 C 左移。
DW 输出为带符号 INT8，ReLU 层为 0..127，head 为 INT16 Q8.8 logit。
正式训练的校准与导出不在本阶段声称完成。

判定每 512 样本一次，最近三次至少两次过阈值；重置后 2048 ms 抑制，命中后
1500 ms 冷却。采样时间不连续重置全网络。静音持续推进，旧词模板不参与新后端。

## 有限验证与交付

1. 主机浮点整段/流式比对，整数 Python/主机 C 所有层比对；极值 PCM、重置、
   舍入边界、冷却、溢出/越界检测；实际执行路径无逐帧分配。
2. 完整 Agent 条件编译，默认旧后端和音频关闭仍可构建；主机功能回归。
3. 备份/校验当前设备，仅应用更新。USB 提交固定 PCM，序号+CRC32 校验，逐帧
   返回全部前端/网络值，与主机对齐。诊断会话阻止冲突操作，取消或 30 s 空闲释放。
4. 600 s 实际麦克风持续流，统计每块完整前端+两次网络+判定的 500 us 直方图及最大值。
   记录资源、DMA/复位，以及联网、音乐、灯控、录音、上下文等有限回归。
5. 汇总 Flash、工作区、栈、堆、耗时与数值报告。结束恢复原来可用固件。

门槛沿用 SPEC XY-05..07：新后端≤64 KiB Flash、应用≤1540096 B；工作区≤16 KiB、
额外栈≤4 KiB、两者≤20 KiB；最低 internal heap≥32 KiB，监听最大块≥24 KiB；
每 512 样本 p99≤16 ms、最大<32 ms。超限只做一轮有依据的优化；仍不满足则
停止扩大训练并报告。诊断会话临时 USB 缓冲单列，不藏入生产后端预算。

数据仅为计算测试。正式的普通话/粤语训练与真人盲测在后续阶段进行。
