## 试什么，为什么试

上一轮[频带增强](WAKE_FREQUENCY_MASK_REPORT.md)未通过；历史 UX202 联合线性头也未通过。本次只试一个固定的非线性小头：保留原 E/L 两条 24 通道模型，拼接它们在每帧推理后的 24+24 个 INT8 隐藏值，再执行 `48→16 ReLU→1`。原模型权重和默认固件代码均未修改。

小头共 801 个可训练参数。C11 的固定权重结构是 852 B，每帧 784 次乘加，没有新神经历史、通用模型解释器、BatchNorm、堆分配或 FFT。中间和输出移位固定为 8、3；偏置的绝对值上限为 1,048,576。48 个极值 INT8 乘积加偏置的上界是 1,835,008，输出层也在 int32 和 FP32 精确整数范围内。

源码在 `prototypes/kws_verify_head/`、`training/kws/verify_head.py`、`training/kws/frozen_pair.py`，均为可选原型，没有加入正常构建。主机编译的评分函数栈报告为 80 B、原两条神经状态为 6,252 B；这些是主机结果，不能替代 C3 栈、实际应用体积、全业务最低堆或实时预算。

修复后的实际合同与提取进程 29.953 秒，计算 27.739 秒，exit0：

- 2,048 个初始、半整数及边界头分数的 FP32、独立 NumPy int64 和 C 值完全一致；四个参数张量的梯度有效。
- 20,000 个独立标量参考、ASan/UBSan 随机与边界测试通过，非法偏置被拒绝。
- 八条 TRAIN 流的有/无 trace 两遍共 4,096 帧一致，核对 102,400 个隐藏值及头值；`current` 中的特征与 C trace 和 F64 相同。
- 提取 17,066 个完整 256 帧 TRAIN 窗口；旧 15,791 窗口的 E/L 全部保存头值和两支隐藏缓存逐项一致。
- 对 6,146 个原正确正锚点与 685,652 个标注负例的预热后机会，五块隐藏上下文没有完全相同的跨标签冲突。

五块对应三块均值加三票决策的原始块跨度。没有精确冲突只排除这一范围的完全相同输入，不证明信息充分、非线性可分、所有训练目标一致或真人泛化。

## 停止和下一步

本次小头配方停止，不评分 DEV 或独立 TEST，不改宽度、移位、阈值、时间窗或损失重训，也不烧录。这个结果只否决这一模型和训练配方，不能证明所有隐藏特征或非线性头都无效。
