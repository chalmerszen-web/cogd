## 目标与标注含义

普通话、粤语“你好，小言”共同输出一个完整唤醒事件。两个输出类是 `no_wake_event` 与 `xiaoyan_wake_event`。前者表示没有唤醒事件，允许自然说话、音乐和噪声；它不声称输入是静音。负样本的空目标因此不需要虚构音节转写。

所有原输入、正负真值、原来源组及普通话/粤语分类保留。语言分类只用于分别统计召回，模型不输出“识别到哪种语言”。正事件只能在已有的 `event_start_accept..event_end+2560 samples` 区间中学习，不编造音节时间。连续运行时不读取测试标签，也没有按词尾标签拖延触发的定时器。

## 模型与事件判定

复用既有 40 带、48 通道因果深度可分离卷积，末层改为两个输出，19154 个参数。输出每 512 个 16 kHz 样本一次，即 32 ms。状态从真实零 PCM 前史开始。

事件判定用最近至多八个输出帧中“恰好一次完整事件”的路径概率；超过全部路径质量的一半，且随后两次 `no_wake_event` 唯一胜出才提交。同一次事件不重复提交。断帧、取消监听及无效样本钟清空判定历史。只有固定窗口和调用方拥有的状态，推理期间不分配堆。

## UX464 数据与覆盖审计

一次检查全部 15791 行原始特征字节：没有发现完全相同特征分别标成正例/负例的冲突，也没有发现完全相同正例必须在互斥时间提交事件的冲突。这不证明不同声音素材没有语义标注问题。
