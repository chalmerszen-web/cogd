# 完整语料保留检查与微调路线结束（UX523）

2026-10-04。**本轮结束，误唤醒尚未修好；没有可烧录的修复版本。结束冻结末层微调路线，不继续同类测试。** 当前实机保持 `0.11.72-summary`，自动唤醒和自动语音关闭，USB 文本交互仍可用。关闭自动唤醒不能算修复。

上一轮仅拟合两段实际输入，虽挡住“小燕”，却丢失大量普通话、粤语正常唤醒。本轮在求解前将完整已知语料的保留条件纳入同一个合同：15,791 条 TRAIN、30 条已揭盲同声音原 WAV，以及两条归因通过的普通话板上输入。沿用原阈值、256 ms 核验规则、定点格式、输入和时间边界。所有基准事件与上一轮保存记录逐条相等；基准是冻结 24 通道 E/L＋48 通道核验模型，不能当作当前设备原 E/L 固件的质量实测。

只提取一次完整特征，约 48.31 秒；产生 98,379 条约束，其中正约束 12,259 条、负约束 86,120 条。一次最小公共松弛线性规划约 3.37 秒，最优松弛为 839.778887，未达到零松弛准入条件。因而没有执行条件整数求解，没有生成提案，没有神经训练、再前向、采放、云调用、C 编译或烧录。运行进程总计约 52.72 秒，已确认 exit 0。

独立审计只重算保存的原始和对偶约束。对偶下界 839.778887319，原始与对偶差约 1.62×10⁻⁹，最大原始约束误差约 3.12×10⁻⁹。它支持**这次登记的合同没有零松弛解**，不能证明所有末层或双语模型都不可能。

合同固定原正常事件的最强支持对，并要求潜在确认范围内的负例分数和原低分位保持低于阈值。这比“保留至少 99% 正常事件、无新增误醒”的最终门槛更严格。因此，本结果的用途是终止当前固定合同的微调实验；不能把它当作放宽验收、放弃双语要求或证明一定需要换芯片的依据。后续如改变特征学习或数据方案，应先给出有限的新计划；不再重复末层拟合、阈值、声音窗口或种子扫描。

两组 SAPI 声音和 TRAIN 都是已知开发材料，不是独立真人盲测。现场每小时误唤醒率、真人泛化、1 秒开口以及整轮 48 KiB 最低堆等旧失败仍保留。三轮完整实际对话尚未完成验收，整体项目不能标记完成。
