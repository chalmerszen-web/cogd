# 误唤醒分数是否能靠提高阈值解决（UX474）

2026-10-04。**误唤醒仍未修好；本轮未改变固件或识别规则。** 利用 UX471 已保存的四条设备输入记录，证明在这对普通话开发声音上，三模型候选的现有确认规则无法仅靠提高两路阈值区分正确词与近似词。

## 固定输入与结果

只读取四条已有合成开发声音对应的 752 块记录，没有再播放、录音、联网、推理、训练、读取独立 TEST 或烧录。原始文件、模型与规则源代码逐项 SHA 校验；序号、512 样本时钟和真实 armed 标志核对通过。此前主机/设备逐块完全一致的证据不重复运行。

现有规则在三个 32 ms 分数中要求至少两票；该窗口能支持的最高阈值等于三个数的中间值。875 个独立比较计数检查与排序公式一致，包含 INT16 极值。下表是每条已保存流中这个两票上限的最高值，不是音频识别率或词音标注。

## 可验证的限制

当前概率门槛 740‰ 对应 Q8 logit 268。只考虑两路门槛分别从 268 提高、两票规则和 256 ms 确认范围保持不变的这一家族：

1. 普通话正确词要产生事件，主门槛必须不超过 566，辅助门槛必须不超过 372；这是由全部已保存 armed 窗口得到的必要条件。
2. 普通话近似词在第 70 块已经提供辅助两票 388；第 72/73 块提供主两票 456/652，且此前不存在主两票达到 268 的候选。
3. 对任何仍能接受该正确词的上述提高门槛，近似词最晚在第 73 块产生主候选，已有辅助支持距它 64 或 96 ms，仍在固定 256 ms 内。因此它也会被接受。

这里没有搜索阈值或选择一组效果较好的参数。三个原始头的全流峰值同样是近词 `[1038,1002,1026]` 高于正确词 `[939,827,764]`，所以只给这些峰值再加更高下限也不能区分这一对。

这个反例**只否定上述提高阈值家族**，不否定全部时间形状特征、新声学模型或其他判定器。它来自已揭盲的合成开发材料，源文本不是经真人确认的实际音素；粤语声源归因在 UX471 的原检查失败仍保留。更不能把候选三模型的辅助分数当作原 `0.11.72-summary` 使用同一辅助后端的证明，或据四个片段计算现场每小时误唤醒。

后续候选需要新的声学区分证据或有来源支持的监督信息，并验证正确普通话、粤语的保留情况。继续对这批分数提高阈值、重放相同刺激或将开发素材转为新训练标签，不能替代这些证据。
