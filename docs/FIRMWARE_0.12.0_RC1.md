# ESP-HI 0.12.0-rc1 用户测试版

2026-10-05。已从当前源码重新构建并烧录到 COM5 的 ESP32-C3，定位为供用户体验测试的候选版本。此前误唤醒、一秒有效回复及其它未通过记录继续保留。

## 如何测试

1. 关闭其它串口窗口，双击项目根目录 `开始语音测试.cmd`。该入口启用本版的快速流式语音配置，并打开串口查看识别和回复。
2. 说“你好，小言”，听到开始提示音再说话。先试短问题，再试灯光控制、上下文追问和普通话／粤语切换。
3. 建议连续说三轮，特别留意回答结束后能否再次唤醒、是否误唤醒、是否漏掉问题后半句、回答是否流畅。
4. 串口输入 `agent voice off` 可停止语音；文字交互入口为 `打开设备对话.cmd`。

现有 Wi-Fi、模型服务配置和历史数据已保留，无需新增安全密钥。使用中遇到问题，可提供说过的原话、实际识别文本和现象。

## 需要你重点体验的限制

- **误唤醒尚未解决。** 这三次成功不能证明现场误唤醒率已经达标。
- **长句可能漏掉后半句。** 额外测试播放“为什么天空是蓝色的？请简单解释一下。”，实际转写只保留前一句；设备回答了前一句，不能算完整输入通过。
- 该额外测试的原脚本还要求旧 `playback` 事件，本版提前回复路径记录 `speaker_start`。原退出码 1 和失败报告均保留，没有改判或重跑救分。
- **一秒有效语音回复尚未验收。** 本次不将提示音、首次 PCM 或软件事件当作一秒听感通过。
- SDK 历史最低堆 **46,572 B**，仍低于原 49,152 B 目标。测试版不是长期高负载稳定性验收通过的正式版。
