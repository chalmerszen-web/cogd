# COGD C3 / P4 整合验证

2026-11-06。本次交付定位为**可拉取的开发候选，整体验收未通过**。产品设计与功能以 P4 `0.9.2-p4-tutor` 为基线；C3、P4 共用核心，按板型分别编译，不能共用固件。S3 只有移植交接，尚未适配或实测。

公开结果索引：[精简验证摘要](evidence/integration-20261106/summary.json)、[已构建源码索引](evidence/integration-20261106/compiled-sources.json)。源码索引记录 92 个 C3、133 个 P4 仓库内编译源文件的 SHA256，不含 SDK、managed_components 或生成输入。原始日志、录音和 Flash 备份保留在开发机 `.local/integration-20261106/`，不随源码分发。

## 实施范围

- 统一入口 `tools/build.ps1 -Board esp-hi-c3|waveshare-p4-3.5`，隔离 SDK 配置、分区与输出目录；未支持芯片会在构建时明确报错。
- 官方唤醒词统一为“你好小智”：C3 使用 `wn9s_nihaoxiaozhi`，P4 使用 `wn10_nihaoxiaozhi`。自研唤醒仅保留为显式历史兼容配置。
- C3 保留 ASR/LLM/TTS、上下文、硬件工具和时钟；为容纳官方模型，关闭提前推测回复并用 100 ms 提示音替代预录进度话术。这些裁剪不应用于 P4。
- P4 保留最新实时对话、插话、异步任务、多媒体、拍题与分步教学实现。新板烧录入口包含字体资产；配网使用显式设备身份及凭据环境变量，成功后恢复 natural 模式和官方本地监听。
- 根架构、规格、构建说明与 [S3 移植指南](PORTING.md)同步到 P4 基线；P4 4.3 目录仍为未实板验收的资料参考。

## 本轮 P4 实机结果

固定音频由主机播放，经 P4 实体麦克风采集；教学题图明确标记为 `test_image_not_camera`。以下用例属于本次新运行，不沿用上游结果。

| 用例 | 判定 | 实际结果 |
|---|---|---|
| `voice-03`，89.45 s | **PASS** | 普通问答与续问、静默告别、播音中主动插话、明确再见及返回监听通过；插话测试音源开始到观测停播为 686 ms；`stream_underruns=0`、`tx_deadline_misses=0` |
| `media-01`，46.63 s | **PASS** | 固定 MP4 本机解码 100 帧，缓存 60 帧，片长 3,999 ms；准备 14,864 ms；3 轮软件触摸事件暂停/继续通过 |
| `tutor-01`，111.23 s | **FAIL** | 题干确认、求解、讲解方式选择、第二步追问、结题均完成；音频欠载 2 次，发送期限超时 0 次，未通过连续性门槛 |
| `tutor-02`，110.86 s | **FAIL** | 同样完成教学步骤；音频欠载 5 次、发送期限超时 3 次，最大发送间隔 2,012 ms，未通过连续性门槛 |

`voice-03-end-check.json` 是对 `voice-03` 已保存物理事件的离线加强复核，确认明确结束不能由静默超时、缺用户输入或缺回复冒充；**不是一次新的声学运行**。686 ms 是这次固定条件下的单次观测，不是人群表现或 P95。

两轮教学均保留整体 FAIL，不因业务步骤完成而改判，也未降低欠载/期限门槛。当前证据尚不能确定其根因。上游在视频并发及结题收尾时出现的偶发 `local_vad` 误打断仍是已知问题，本次整合未证明修复。

媒体用例没有实手指触摸或语音/视频并发验收。教学用例没有重测真实纸张识别、手指滑动、五分钟阅读暂停及长步骤分页。500 ms 自然回复、广泛误唤醒率、真人远场和长时耐久仍未达标或未完成验证。

## 保留的早期失败

- `voice-01`：测试框架在设备自行校时完成前检查时钟而失败。修正为有界等待自主校时，未由主机注入时间；原失败报告保留。
- `voice-02`：串口日志交错导致结束事件采集/判定超时。修正读取与判定后另跑 `voice-03`；原失败仍保留，不把后续 PASS 回填到旧运行。
- C3 官方模型接入期间的配置和容量失败日志保留；最终通过构建采用上文的明确资源裁剪，不修改应用分区掩盖超限。
