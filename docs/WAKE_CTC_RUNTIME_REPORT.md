# 连续音节推理与完整训练数据

2026-10-03，UX452–455。现场误唤醒尚未修复。本报告中的 C 测试验证状态、运算和接口；模型在普通话、粤语、近似词及背景人声中的识别效果必须另测。

## 已通过的运行时检查

新增隔离的纯 C11 `kws_ctc_runtime`，复用现有定点前端和因果卷积。它以真实零 PCM 对应的归一化特征计算稳定前史，直接填充各层环形缓存；重启监听不需要先等待两秒虚拟音频。遇到断帧、禁用、重新启用或无效输入时清除音节证据。禁用期间跳过 FFT 和神经网络计算。

独立的 14 类头每 512 样本输出一次。只有按顺序识别普通话或粤语的完整四音节，再收到两帧 blank，才产生目标事件；旧 scalar 头标记为未训练且不参与决定。调用者仍须负责播放/录音排他和冷却。

| 检查 | 结果 |
|---|---|
| 合成模型初始化与原 C 逐帧预热 | 24/48 通道各八个模型，16 个状态完全一致 |
| 初始化后的运算 | 1,626,112 个层输出值完全一致 |
| 四音节、错误词尾、断帧、重新监听、未训练模型禁止事件 | 通过 |
| ASan / UBSan | 通过 |

这些是交叉编译对象及主机测量，**不是**已链接应用大小、板上 32 ms 实时性能、最低堆或声学识别率。合成测试前端不能当作真实麦克风输入。模块暂未进入默认 ESP-IDF 构建。

UX452 首次统计遇到 Windows `nm` 的 CRLF 行尾，原进程退出 1；保留失败后，仅解析同一批对象修正收据，没有重新测试。UX453 首次 PowerShell 内联脚本解析失败，未开始测试；改为保存 Python 文件后，唯一实际检查通过。原记录均保留。

## 数据与监督合同

UX454 保留全部 15,791 条基础 TRAIN 输入、161,699,840 个原始归一化 INT8 值，以及旧正负标签和来源元数据。其中 7,091 条有完整词及原 PCM 哈希依据，包括 6,295 条目标词和 796 条近似词；另有 8,700 条未知负例。

完整普通话目标使用 NI、HAO、XIAO、YAN2，完整粤语目标使用 NEI、HOU、SIU、JIN4。已核验的近似词在相应词尾使用 OTHER，没有把仅有文字的录音冒充精确声调标注。未知负例只使用一个 OTHER 类别，表示整段未知负输入，**不是**对自然人声的音节转录。只有实际零 PCM 使用空目标。片段不能赋予完整唤醒词标签。

训练损失支持长度 0、1、4。已验证的静音前史只能走 blank 路径，后续保留整段输入的 CTC 路径概率；独立双精度前向、重复 token、梯度和无效输入检查通过。该合同不读取 DEV/TEST，不选择得分高的样本，不改变旧真假标签。它只覆盖基础训练输入，尚不包含另存的 231 个连续父流。

## 一次正式训练

UX455 从新随机初始化训练 48 通道、19,742 参数的单模型，固定种子 20261003455、Adam 0.003、CPU 四线程，最多 6,000 步 / 420 秒，只保留最终 checkpoint。每 batch 有普通话和粤语目标各四条、各类近似词各一条、八条未知负例和两条真实静音；按照已声明的来源组抽样，不按模型分数选样。

训练与评分均使用经核验的稳定静音前史，保留原 256 帧输入。评分用原 C 序列解码器，逐条记录触发语言、次数和样本位置。准入及停止条件在训练前冻结：每语言有效召回至少 99%，已知近似词和自然负例无事件，负例总触发不超过 18 条，无提前或错误语言事件，静音无 token / 事件。任一失败即停止该配方；不通过调整阈值、选择 epoch 或第二次训练改变成绩。通过 TRAIN 也不代表独立真人测试或每小时误醒率。

首次入口因 Windows 创建的 runner 路径含反斜杠，在输入校验时失败，尚未构造模型或更新优化器。`plan-r1.json` 只修正路径并新增独立进程收据，保留原失败文件；数据、种子、训练步数、算法和准入不变。

## UX455 结果：失败，停止部署

唯一实际拟合完成 6,000 步，约 205.1 秒。抽样覆盖 14,112 / 15,791 条输入；全部 15,791 条均参与固定评分。来源组均衡抽样不保证有限步数内每个增强版本都被优化器抽到，这一点不能省略。checkpoint SHA256 为 `ee58fa75f2d6760af2440646a5fb2f32d7db91e66e341d7721c72cb5608d72cc`。

| 冻结 TRAIN 检查 | 结果 |
|---|---|
| 普通话有效完整事件 | 1,054 / 3,637，28.98%，失败 |
| 粤语有效完整事件 | 1,182 / 2,658，44.47%，失败 |
| 负例窗口触发 | 46 / 9,496，超过 18，失败 |
| 已知近似词窗口触发 | 17 / 796，失败 |
| 自然人声负例窗口触发 | 7 / 2,225，失败 |
| 提前触发 / 错误语言 | 2,339 / 0，提前条件失败 |
| 实际零 PCM | 无 token、无事件，通过 |

“有效”要求只有一个正确语言事件，且位于原 `event_start_accept` 至原 `event_end + 320 ms` 内。仅有正确语言事件的窗口为普通话 2,791、粤语 2,206；其中 1,717、622 条发生在原允许区间之前，不能用这些较高数字掩盖时序失败。原标注保持，没有事后移动边界。

46 条残留负例中有 14 条“小燕”、21 条截词和七条自然人声。只从已保存结果做了一次分类和时序汇总，没有重推理或换规则。整段 CTC 只限制 token 顺序和路径概率，没有约束最终音节可以出现的时间；因此完整词文本标签并不保证模型确实等到完整声学词尾。此结论针对新实验，不能推断旧 0.11.72 每次现场误唤醒都是同一成因。数据也没有精确音节时间戳。

声学网络评分仍是主机浮点，序列判断使用实际 C 代码。这是 TRAIN 窗口成绩，**不是**实机监听的每小时误醒率，也不能与不同输入/控制器的旧整数成绩直接计算改善百分比。失败后未执行校准、权重 C 导出、独立 DEV/TEST、麦克风采集或候选烧录。

评分结果完整保存后，首次 JSON 汇总遇到 NumPy bool 类型退出 1；原进程、runner、checkpoint、logits、事件和失败清单均保留。随后只对同一份缓存显式转换为 Python bool 写出报告，没有重新评分、训练或改变门槛；原评分分段计时未保存，报告标为 null。

收尾 13 项 CTC Python 单元检查通过，包含独立路径概率、梯度、连续内存、整数导出护栏、重复 token 和分块合同。四条只读 USB 查询确认设备仍为 `0.11.72-summary`、wake / voice off、空闲；上下文 1,362 条、929,888 B，2 MiB 分区及 204,800 B 历史预算保持。COM5 已释放。本阶段没有 Flash 写入或采放新声音，完整语音目标和现场误唤醒修复均未完成。

## UX456：已有词尾标注的独立时序监督

下一种训练目标仅允许正词的最终 token 出现在原 `event_start_accept` 至原 `event_end + 160 ms` 内。它使用已有完整词结束标注，不冒充精确音节时间戳。其他词、片段、自然人声和真正静音的标签保持；运行时的解码器也保持，不增加计时屏蔽、等待或门槛。

算法先将允许的类别归一化送入标准 CTC，再减去每帧允许概率质量的对数，恢复原分布中这些合法路径的概率和梯度；若只归一化而不恢复质量，会改变训练目标。独立概率前向及全部 224 个浮点输入的有限差分梯度通过，未受时序约束时与原混合 CTC 值和梯度一致。全部 6,295 条原正词的 512 样本时间坐标核验通过；另 9,496 条负例保持无此时间限制。新旧共 16 项单元检查通过。

开发草稿使用 `-inf` 屏蔽，正向结果正确但本机 CPU CTC 反向出现 NaN，原代码及失败已封存。固定数值合同采用有界有限 logits 和 `-4096` 禁止类别值，使概率在双精度下溢为零并避免该内核问题；没有扫描屏蔽值。

UX457 是同网络、数据、原真假标签、种子、抽样顺序、最终步数和验收条件的唯一新目标对照，从新权重开始。它不会改变 UX455 的失败，也不把训练时间约束搬到实际音频监听中。
