# 同模型浮点与 INT8 诊断

2026-10-02，UX265。误唤醒尚未修好；UX264 模型继续被拒绝，没有烧录。设备核对为原 `0.11.72-summary`、自动唤醒和语音关闭，USB 文本可用。

只使用 UX264 的同一最终 checkpoint、冻结 BatchNorm、归一化和既定判定。浮点头乘 256 后 round-away、限制到 INT16，再走原三块均值、向零截断及 268/twoof3/64 块预热/24000 样本冷却。没有训练、重新校准或阈值搜索。主机浮点输出仅用于诊断，没有声称能按该实现部署到 C3。

浮点已存在明显漏醒、新误触和提前触发。量化改变了部分事件，但仅调整量化不能解释或修好主要退步；训练结果与实际唤醒条件的关系需要继续检查。不同分组的改善不能抵消旧正例损失。

数值前提通过：同 checkpoint 的逐帧、变长分块、独立批样本和因果前缀对齐；独立 F64 BN 折叠最大误差 `1.24e-5`；4096 项独立均值及 Q8 极值检查。预先选定的 22 条完整输入中，逐层整数结果与 UX264 的 C 已验证缓存一致。全部 UX264 PTQ 分类统计也逐项重现；额外 168 条原事件由其完整差异记录重建，明确没有重新运行原 C。

对全部真实长度做比较，不把补齐尾计入统计。浮点与 INT8 的旧分数平均绝对差 55.01 Q8，固定阈值的块判定翻转 21619 次；事件变化和两者各自相对原版的损失完整保存。逐层 `clipped_fraction` 包含 ReLU 的低端截断，不能把它解释为量化上饱和率。

唯一实际诊断耗时 21.86 秒。首次 WSL 启动因 Windows 路径反斜杠报 file-not-found，没有开始实验；错误原样保留，修正 argv 后才运行本次诊断。没有读取开发集或项目独立 TEST，没有录放、云调用或 Flash 写入。这些材料是已知 TRAIN 和此前公开源设备采集，不能充当真人盲测或每小时误触率。

证据位于 `artifacts/voice-fast/wake-float-int-diagnostic-ux265/`，包括冻结计划、两种分数、事件差异、数值检查、源码归档和 USB 结束状态。原历史、录音、音量、灯及摘要保持，USB 已释放。完整语音业务目标保持未完成。
