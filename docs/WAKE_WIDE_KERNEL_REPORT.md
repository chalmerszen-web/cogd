# 更宽声学内核的准入检查

2026-10-02，UX260。**48通道C11主机数值与安全检查通过；没有训练、烧录或证明误唤醒改善。C3的Flash、堆和实时预算仍需实测。**

此前对原分支符号否决的有限检查未能充分清除误触且增加漏醒，已停止。这里为重新设计声学分类器建立独立的48通道运行前提，不继续拟合失败的小模型。

内核支持编译时24/48两种固定宽度，默认24的ABI、工作区、模型及行为保持。每个构建只分配自己的固定状态，不在运行时扩大通道，不增加通用解释器或C++库。40维前端、12层因果结构及127帧感受野不变；48通道使用6032字节神经历史和529个层输出。错误宽度、拓扑、溢出偏置及Python/C trace布局不匹配均拒绝。

48检查权重使用固定seed2026100260，18528个密集非零INT8值，明确`trained=false`，不能触发唤醒。它用于检查真实乘加路径、导出布局和固定缓冲；不来自训练checkpoint，不是待推广的分类模型。模型、独立参考、原C基线、日志与hash在`artifacts/voice-fast/wake-wide-kernel-ux260/`。

设备通过USB核对仍为原`0.11.72-summary`，自动唤醒/语音off，安装版工作区12632B。上下文1290事件/897144B/next4517、2MiB分区及204800B历史预算未变。安装版与当前源码的工作区差异包含之前的FFT存储优化，不能把全差值归因于本次通道改变。

正式训练必须等待独立的C3数值、Flash、32ms输入块和堆预算检查通过。后续真实分类候选仍须普通话、粤语和近似词/自然人声对照，以及至少三轮连续完整业务；此次主机准入不替代任何这些验收。

## 训练与导出前提

UX263为trainer增加显式`--channels 48`，旧默认24不变。checkpoint宽度必须与stem tensor一致；旧缺省元数据只接受24。校准的各层几何跟随网络，48导出附编译时ABI检查。旧24 checkpoint的新旧完整校准JSON/C字节一致。

人工随机8clip的每宽度一次优化步骤验证梯度、保存、校准和导出；48导出的2166784层值与C/NumPy/F64参考一致，512 PCM完整trace一致。这是训练工具的数值测试，没有读取实际语音语料或证明识别效果；这个synthetic checkpoint不会烧录。现有QAT脚本仍只用于原契约，没有宣称扩宽支持。正式声学候选须另定数据和有限fit/质量准入。
