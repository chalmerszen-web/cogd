## 新的整数训练合同

新增 `training/kws/conditioned_integer_qat.py` 和 `tests/kws/test_conditioned_integer_qat.py`。这是主机训练后端，未修改默认固件或C推理内核。

固定90输入、24通道、12层、9984个INT8权重。训练中每层采用与C相同的权重取整、整数累加、requantization、ReLU及限幅，通过直通梯度更新权重；偏置、shift和输入归一化固定。浮点32位卷积仅用于计算可精确表示的整数累加，保守部分和上限4442335；再以浮点64位处理移位取整。没有BatchNorm，没有重新收集量化范围，没有第二次PTQ，也没有词尾辅助分类头。

初始化仅使用已拒绝UX422模型的整数权重及固定尺度，保留来源hash；这不表示UX422浮点配方重新运行或已获采用。旧辅助分类配方仍停止。

UX428初始模型及预先固定的模拟整数更新均与独立F64、Torch整数和C对齐，共2170880个全层值。63种shift、203520个带因果前文/掩码的值、梯度、五种checkpoint错误及四种输入错误检查通过。该检查证明数值合同，**不是C3识别效果或资源验收**。C辅助状态3276B沿用现有内核。

合成批35×382帧CPU4前向/反向中位69.24ms，预估6000步415.45秒；实际完整训练196.82秒。预估与实际不是同一负载，不把预估值报告成训练耗时。
