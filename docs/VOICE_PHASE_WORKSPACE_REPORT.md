## 实现

UX69 将消息、回复、SSE 和请求缓冲独立为调用方持有的
`agent_engine_workspace_t`。C3 大小仍为 **54416 B**，配置、熔断状态和
对话标识不随工作区释放。绑定同时更新上下文序列化指针；拒绝容量不足、
未对齐、活动语音输出及正在使用的历史选择。未绑定时，在任何网络或工具
动作之前返回内存错误。这一基础版本仍使用静态存储，未烧录。

UX70 只在现有实验 `AGENT_TEXT_PREFETCH` 构建中启用分阶段分配：

| 阶段 | 工作区和归属 |
|---|---|
| 普通 Agent 对话 | 完整 54416 B，原缓冲容量不变 |
| 已确定的 fast 录音 | 28216 B：17024 B 候选控制区＋3000 B 源帧记录＋8192 B ASR |
| TLS 配置完成且收到候选类别 | 再分配原有 24576 B IMA 音频缓存 |
| 完成或放弃候选 | 关闭并等待任务退出，再释放缓存和录音工作区，恢复完整工作区 |

握手期间减少 **26200 B** 预留；音频缓存分配失败则不发送生成请求。
实际 C3 候选控制结构为 **16432 B**，含原 6 KiB 静态任务栈和 8 KiB 解析
缓冲，留有对齐空间。主机 64 位结构较大，初始 16640 B 前缀触发了编译期
边界检查；最终双方统一为 17024 B，失败日志保留。

录音在提示音之前冻结 fast 选择，直接使用此前已存在的本地频谱端点，省去
构造后立即关闭 TEN 的过程。700 ms 静音、源帧范围、完整 ASR 和录音校验
规则不变。网络任务使用这次实际分配的类型，不重新猜测模式。

恢复完整工作区时目前还会释放已关闭的 WSS 票据，目的是避免小对象影响
大块分配；这也可能影响后续握手，尚未单独量化。票据存在不等于服务器
接受了 TLS 会话恢复。后续应检查是否必须释放，不能假定它没有性能代价。

候选仍要求完整响应、完整输入一致、采集成功和任务退出后才播放；最终
ASR 之后最多额外等 500 ms。未放宽改口、工具权限、输入或存储容量。
2 MiB 上下文、204800 B 历史预算和 448 KiB 录音分区保持不变。

## 唯一实机组

三次唤醒素材分别是普通话／粤语／普通话；请求均为普通话
“请用一句话介绍你自己”。电脑扬声器输入，Misiom-Shooter 麦克风实录。
三次均首次唤醒、完整转写并回退回答；DMA 丢失 0，未观察到复位。

| 指标 | 第 1 轮 | 第 2 轮 | 第 3 轮 |
|---|---:|---:|---:|
| 候选提名距 VAD 结束 | 提前169 ms | 提前216 ms | 提前172 ms |
| 实际请求距 VAD 结束 | 提前43 ms | 提前86 ms | 提前74 ms |
| 请求至候选首 PCM | 551 ms | 551 ms | 587 ms |
| 最终 ASR 至候选首 PCM | 299 ms | 206 ms | 302 ms |
| 取消时收到的样本 | 10240 | 15360 | 10240 |
| 候选获准播放 | 否 | 否 | 否 |
| 回退回答的实录起声候选 | 8.056 s | 8.325 s | 7.923 s |
| 对话结束时空闲堆 | 87512 B | 87348 B | 87152 B |

候选任务剩余栈 2344 B，网络任务剩余栈 1116 B。三轮不足以判断 360 B
末端堆变化是保留对象还是泄漏。声音时间来自波形对齐、能量起点和本地
SenseVoice 复核，不是主观听感或首个有效音素的精确测量。没有执行改口组
或长测；这些固定素材不能证明真人泛化和粤语回复效果。

首轮候选完成前 SDK 累计最低值 57680 B，后续恢复工作区时变为 41300 B，
TTS 期间最终变为 **23888 B**。原有整轮 48 KiB 检查仍按未通过保留。
这里还需区分统计含义：ESP-IDF 将不同内存区各自的最低值相加，各区可能在
不同时间达到最低点，结果可以小于任何同一时刻的真实总空闲内存。
[乐鑫接口说明](https://github.com/espressif/esp-idf/blob/master/components/heap/include/esp_heap_caps.h)
及本地固定 SDK 的 `components/heap/include/esp_heap_caps.h:229` 均说明了此点。

本次恢复工作区前后实际采样空闲堆为 96536／95756 B，而累计最低值从
57680 跳到 41300 B，值得用分配钩子进一步核对。但采样不能排除瞬时低点，
**不能据此将 23888 B 改写为通过，也不能将首轮局部数字当作整轮验收**。
