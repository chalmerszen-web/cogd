# 独立真人与现场距离核验

目前设备仍为0.7.0-xiaoyan-exp、E/F模型。候选G/H/I未达到全部门槛，未覆盖当前固件。
近距离播放并降低数字音量，只是弱信号测试，不能证明真实5米。

剩余关键证据是自然普通话/粤语的正确发音，以及现场实测距离下的麦克风输入。
机器对一条“小燕”合成负例的音高检查没有得出可靠词音结论；其原标签和失败结果保留。

## 在场时采集

1. 关闭串口对话窗口，暂停其他音乐和人声。双击根目录“采集真人唤醒样本.cmd”。
2. 选择自己能够自然说的语言，实测并输入嘴到设备麦克风的距离。输入匿名说话人编号（如 p01），同一个人在所有距离使用同一编号。先采近距离0.5米，再单独采5米；不要用降低电脑音量替代距离。
3. 按提示说“你好，小言”或“你好，小燕”。按回车后有10秒就位，绿灯期间说话；记录完后确认是否完整说对。可以用无线键盘或由另一人在电脑旁操作。
4. 每种语言默认各3次正例和3次近似词，属于首批诊断材料，不是统计充分的最终验收。随时Ctrl+C退出。

不会自动训练、烧录或上传；新录音位于本机`artifacts/kws-human-review/日期时间/`，不进入Git。
采集前会导出原设备录音槽，之后该槽会被新录音替换；上下文与Wi-Fi/API配置不改动。
启动器和帮助入口已检查；正常结束、串口占用、录音超时、确认前中断和关闭失败五项模拟检查通过。模拟检查只验证材料保存及清理逻辑；完整真人流程需要人在场执行，尚未声称通过现场测试。

录音包含匿名说话人编号、预期文本、本人确认、用户报告的距离、ADC状态和PCM校验值。确认前退出的录音会保留并标记为待确认；软件不能独立证实物理距离或母语读音。
这些材料默认保留用于独立核验，不能不经来源划分就混入训练；应分别报告普通话、粤语、距离、漏检与误触发。

## 参考声音审阅

需要核对的合成负例是`dataset-yue-zf_xiaoxiao-0-001-bounded1`。请求文字为“你好小燕”，
早期自动转写为“你好小演今日天气好好”。两者都不构成人工音素真值。
原音频在`artifacts/kws-phase3/development/`，完整音高检查在`artifacts/kws-phase5/yue-pitch-diagnosis/`。
不因单个难例删样、改标签或提高成绩。独立人声将帮助区分合成素材问题、近似词区分能力和声学输入限制。
