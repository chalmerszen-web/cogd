原 UX520 已归因输入只有慧慧目标词和康康“小燕”。直接在这两条录音上学习，会把声源与标签混在一起。本轮补采康康“你好小言”和慧慧“你好小燕”，每条两个固定回放，共两条 384 块输入流、四次播放。使用原 0.14 RMS/0.35 播放增益、740 阈值、16 kHz 校正时钟和原三频带波形／包络／间距／竞争者门槛。自动业务动作被诊断接口抑制，不调用 ASR、LLM 或 TTS。

两流的实际采样率估计分别为 15999.936 Hz、15999.795 Hz，均通过原 500 ppm 门槛，无满幅削波。原 C 库对 768 个新块的头、平滑分数及事件全部重现，无数值不一致；25 个编译依赖的哈希与原库相符。两个目标触发计数不能绕过波形失败而当作目标有效率。

原慧慧目标输入和本轮慧慧近词输入组成一个通过原归因的同声音正负对照。两声音、两标签的完整四单元矩阵仍缺少合格的康康目标流，因此本轮没有准入完整训练矩阵，也没有生成训练特征缓存或从未归因录音学习。两个 SAPI 声音都已揭盲；这不是独立真人准确率或现场每小时误唤醒率证明。源 WAV 和固定能量边界也不等于人工音节标注。
