## 资源所有权切入点

源码核实：完整HTTP响应返回后，语音engine调用answer_end并等待TTS完成；voice请求允许HTTP复用，平台可因此把已经读完的HTTP连接保留到播音结束。后续可以仅在最终answer_end入口关闭该已经返回的HTTP连接，保留origin handle/session ticket；不能在on_sent、feed、进度应答或中间工具轮中关闭仍被HTTP owner使用的连接。本阶段尚未实施这一修改，也未声称可回收确定字节。
