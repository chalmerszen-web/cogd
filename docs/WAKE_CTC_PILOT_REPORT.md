## 固定实验及结果

只使用已有 TRAIN 中有完整词来源依据的 64 条输入：普通话、粤语各八种词，每种四条。原始 PCM 来源哈希及完整词证明匹配；近似词缺少独立声调标注时标为 OTHER，没有凭文字把它们伪装成已经标注的声调类。能量结束区间也不是音节时间戳。此集合没有自然环境负例，不能据此计算每小时误唤醒率。

新模型为 48 通道因果深度可分离卷积，14 类头，19,742 个训练参数；每 512 样本输出一次。固定种子 20261003447、Adam 0.003、batch 16、CPU 四线程，仅训练一次 1,200 步并保留最终 checkpoint。损失从 77.154 降至 0.085，优化循环约 15.3 秒。旧单输出和八类失败配方没有重新启动。

## 解码诊断的新证据

对同一批缓存 logits 做独立双精度 CTC 前向求和，与本机 PyTorch 2.6 的 CTC loss 最大差为 1.63e-15。17 条 greedy 错误的字符串都比完整正确标签的总概率低。三条普通话漏例中，完整四音节序列概率约 0.618，漏首音节的三音节序列约 0.380。

这符合 [CTC 论文](https://www.cs.toronto.edu/~graves/icml_2006.pdf) 对路径概率求和与单路径解码的区分，支持下一步有限验证 prefix beam 解码。它不是所有可能字符串的最大概率证明，不允许删除“你”音节、强制补词、放宽原准入或将本次失败改为通过。需让 OTHER、错误词尾及不完整序列参与竞争，并另验连续状态和资源预算。

源码：`training/kws/ctc_data.py`、`ctc_model.py`、`components/kws_c11/kws_ctc_head.c` 及头文件、相关主机测试。证据位于 `artifacts/voice-fast/wake-ctc-pilot-ux447/`：输入清单、唯一 checkpoint、原始及修正报告、原 fit 封存包、概率核对及收尾清单。原设备最近只读核验仍为 0.11.72-summary、自动唤醒/语音关闭；本阶段没有进行新的 USB 查询。

## UX448：八候选概率解码也未通过

新增主机用 prefix beam，固定宽度八，全部 14 类竞争，不加词典或补字。三个单元检查通过：1,620 条独立短路径枚举、重复/blank/OTHER/缺首音节、流式分块及边界。只解码上述缓存 logits 一次，约 0.57 秒，没有模型推理或重训。

完整目标普通话 4/4，粤语却降到 2/4；近似词 0/56 触发，完整标签只有 50/64，仍失败。14 条粤语错误均是在正确序列前插入 NI，而不是漏掉词尾。保留概率总量不等于校准置信度，也不能把离线完整输入排名当作连续设备唤醒事件。

缓存核对发现普通话漏例和粤语插入例的 NI 峰都在第八个 32 ms 输出附近；选定两条输入前 118 个 16 ms 特征帧逐值相同，NI 峰概率同为 0.3914。这提示模型在尚无区别的开头学习了类别先验。此时不能通过删除开头、忽略错误语言或增加词典强制约束冒充声学识别改善。下一步应先核对该共同前缀的 PCM/特征来源，并设计空白监督；两次已失败的候选均保持未部署。

UX448 证据在 `artifacts/voice-fast/wake-ctc-beam-ux448/`，源码为 `training/kws/ctc_beam.py` 和 `tests/kws/test_ctc_beam.py`。尚无 C3 beam 实现或资源实测。

## UX449：固定开头来源已确认，空白均值损失不足

通过原 PCM 哈希、放置算法和原 C 前端重建两条输入，20,480 个旧特征值完全一致。两条的第一个非零 PCM 分别在 1.892、1.877 秒，而 NI 峰在 0.288 秒，期间为真正的数字静音。因此这个小样机的 NI 输出没有来自当时的人声。此证据只针对小样机，不能倒推已安装的旧模型每次现场误醒均有相同原因。

新增 empty-transcript CTC 损失，与独立 blank 对数概率及全部梯度双精度对齐；真实 65,536 零 PCM 通过原 C 前端生成空白特征，没有把归一化特征误设为零。旧 64 条输入保持，唯一新随机训练在联合 batch 中加入四份空白，每帧归一化的空白损失加完整词 CTC 损失。仍只训练 1,200 步，约 17.8 秒。

本次原 C 事件普通话 0/4、粤语 0/4，近似词 0/56，完整标签 40/64；空白也错误输出 NI、HAO，未通过并停止，未校准导出。空白损失为逐帧均值，允许少量错误音节峰被长段 blank 稀释；零目标事件也不能当作误唤醒修复。原始 checkpoint、输入、完整报告和失败保留在 `wake-ctc-blank-ux449/`。

下一种监督须直接约束已知数字静音前缀的整个路径概率，保持真正词语的所有音节；不能继续重复本次平均空白损失的训练。
