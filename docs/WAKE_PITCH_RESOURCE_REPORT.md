## 修改与数值保证

`prototypes/kws_pitch/pitch_fast.c` 只将每个 lag 的差分和由64位改为32位。配对采样除32后，窗口值严格位于[-2048,2047]；256项的和最多为256×4095²=4,292,870,400，小于 UINT32_MAX。累计差分和归一化分子继续使用64位，门槛、窗口、输出格式均未改变。

UX383用2048帧全幅随机、极端直流、相邻/成对极值、低高周期输入及合法随机窗口，逐帧比较原版全部状态字节和两个特征，ASan/UBSan、C11 Werror通过。新增训练端 `training/kws/pitch_frontend.py` 直接调用相同C实现；两个绑定测试覆盖独立C导出、分块连续状态、重置、非法输入不改状态。

集成只使用隔离 `.local/kws-pitch-ux382/384` 项目。实际C3 ABI确认工作区从14,232增至15,008B，增加776B；其中基频状态770B，其他为值、计时和对齐。与旧未训练资源固件相比，新应用增加816B。正常CMake不引用这个原型，尚未进行生产集成。
