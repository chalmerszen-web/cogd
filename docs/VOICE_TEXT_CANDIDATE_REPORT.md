**机制已接通，提速验收失败；设备已恢复 0.11.72-summary。** 三轮预测均因

## 实现与边界

默认关闭 `AGENT_TEXT_PREFETCH`；开启时要求音频和独立 ASR，禁止同时启用
连接探针。USB 仍使用 `voice mode fast`、`voice prefetch on` 选择实验路线。
普通 fast 模式保留。仅在这个编译选项下排除旧的同一 Omni 会话预测分支，
避免两套实验代码同时占用 Flash；历史 72/97 的可编译归档保留。

ASR 先握手；随后独立任务准备第二条连接，录音及上传继续。临时文本只通过
现有自我介绍／灯光／记忆三类窄语法提出一个候选，不是通用意图理解模型。
每轮至多一次生成，不自动重试。候选请求为规范化的类别文本，不包含猜测
颜色和记忆内容；原始完整转写仍是普通 Agent 的输入和持久记录。

固定 `qwen3.5-omni-flash-realtime`、Tina、16 kHz、96 tokens，关闭工具和搜索。
校验配置回执、唯一文本项确认、响应身份、完整音频响应及文本。服务器分段
版本改变、改口或取消会作废候选。完整输入、录音校验和任务退出均通过后，
才允许播放。任务回执是将来式短句，GPIO 等操作仍交给最终输入对应的流程。

候选实际 C3 结构 **41008 B**，含 24 KiB IMA、8 KiB 解析缓冲、6 KiB 静态
任务栈、TCB 和状态。最多再用 15 B 对齐，全部位于真实可借用的 43224 B
前缀，避开 3000 B 源帧元数据及尾部 ASR 缓冲。任务关闭自己的 TLS 后挂起，
主线程等待挂起并同步删除，随后才复用缓冲；未强制中断握手、释放仍在使用的
内存或缩减上下文。候选任务实测剩余栈 **2344 B**。

## 唯一三轮实机组

电脑扬声器播放既有素材，Misiom-Shooter 麦克风记录设备输出。三次唤醒分别
用普通话／粤语／普通话素材；三次请求都是普通话“请用一句话介绍你自己”。
这组不能证明粤语生成效果或真人泛化。

| 指标 | 第 1 轮 | 第 2 轮 | 第 3 轮 |
|---|---:|---:|---:|
| 首次唤醒、完整转写及回退回答 | 成功 | 成功 | 成功 |
| 类别候选提出距 VAD 结束 | 提前149 ms | 提前209 ms | 提前124 ms |
| 实际生成请求相对 VAD 结束 | 提前45 ms | 提前94 ms | 延后8 ms |
| 请求至候选首 PCM | 448 ms | 595 ms | 538 ms |
| 最终 ASR 至候选首 PCM | 138 ms | 265 ms | 276 ms |
| 截止时收到的候选样本 | 10240 | 10240 | 10240 |
| 候选获准播放 | 否 | 否 | 否 |
| 累计最低空闲堆 | 37152 B | 30092 B | 30092 B |
| 回退后的实录起声候选 | 9.187 s | 7.724 s | 8.195 s |

500 ms 是完整 ASR 之后给予候选的额外等待上限，不是云端超时值。三次候选
均只收到部分音频，完整响应未到就被主动取消，没有播放残缺语音或重新发出
同一候选请求。**在 VAD 之前提出候选，并不证明在人实际说完之前就准备好了。**
本次关键词出现得晚，加上连接准备及完整响应等待，预测没有转化为起声优势。

最低堆比 48 KiB 门槛少 **19060 B**。候选记录的 `sampled_heap_low` 只是在
握手结束及轮询后采样，不能代替系统最低堆，也不能掩盖握手瞬时峰值。整个
设备网络任务剩余栈为 **1096 B**；DMA 丢失 0，三轮未观察到复位。
轮末空闲堆 87852/87636/87468 B，不能从三轮将下降归类为泄漏或正常保留。
由于资源门槛失败，未追加改口组、长测或真实取消时延验收。

声学数字来自固定波形对齐、能量起点和本地 SenseVoice 内容复核，不是主观
试听，也不确认“第一个有用音素”的精确时间。原始录音约 51.9 秒，保存在
`artifacts/voice-fast/text-worker-ux68-greeting-01/speaker.wav`。
