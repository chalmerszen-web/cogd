# 语音响应提速实测：0.8.1-voice-speed

2026-09-22。在原有设备代码上优化并实机烧录，保持 200 KiB 历史选择预算、
2 MiB 上下文分区、凭据、唤醒模型、DeepSeek、GPIO 和音频业务不变。

## 对比结果

六组相同的合成语音素材，含普通话/粤语唤醒各三组，正文指令以普通话为主。
逐一核对输入文件 SHA256，播放设备、增益、麦克风及音量 80 保持相同。
旧版数据来自 0.8.0 已保存的同素材测试，新版在同一台 ESP-HI 上测量。

| 指标（中位数） | 0.8.0 | 0.8.1 |
|---|---:|---:|
| 输入语音播放完到设备开播事件 | 45.64 秒 | **19.03 秒** |
| VAD 结束到首 PCM | 43.99 秒 | **17.63 秒** |
| VAD 结束到回复播完 | 47.68 秒 | 26.44 秒 |
| 获取上传凭证并上传录音 | 7.60 秒 | 3.69 秒 |
| 提交识别任务 | 3.44 秒 | 0.19 秒 |
| 识别等待及结果下载 | 22.18 秒 | 6.80 秒 |
| DeepSeek 与工具处理 | 4.01 秒 | 3.19 秒 |
| 请求 TTS 到首 PCM | 5.01 秒 | 1.52 秒 |

本轮“输入结束到开播”中位数降低 **58.3%**。这是六个固定样本的观测改善，
不是固定速度承诺，也不能全部归因于代码：云端识别排队在这轮也更短。
没有随机交错控制云端负载。新版完整范围为输入结束后 **14.22–40.84 秒**，
VAD 后首 PCM 为 13.06–39.56 秒。平台排队严重时仍会等待较久。

开播指标使用设备 WAV 首 PCM 事件；它与扬声器真正发声之间仍有队列预填充和
音频自身前导静音，因此不宣称逐采样测得真人感知延迟。外部麦克风录音另作
回答内容和输出质量核对。各阶段中位数也不能简单相加。

把 ASR 等待及结果下载单独列出后，其余阶段合计中位数从 20.61 秒降至 9.92 秒。
这能帮助区分网络/提交/TTS 等改动与云排队波动，但仍不是严格隔离的因果实验。

## 改动

1. 同一事务、同一鉴权服务的请求复用连接，避免每次 ASR 进度查询完整握手。
2. 使用 ESP-IDF 已有的 TLS 会话恢复。平台句柄在不用时关闭套接字，仅保留
   恢复所需状态，最多 120 秒；到期释放，改凭据时清除。切换服务先关闭活连接，
   不同时打开多条 TLS，不缓存公有上传/下载 URL，不跨服务传递 Authorization。
3. 用已有 1 KiB I/O 缓冲合并细碎 JSON 写入，关闭 TCP Nagle 延迟；没有为了
   提速增加大块常驻音频或历史缓冲。PCM 上传生产块从 512 字节改为 2048 字节。
4. ASR 短任务先每秒查进度，再退避到 2/5 秒，保留 180 秒截止和有限 GET 重试。
   未知结果的收费 POST 不自动重发。
5. 语音提示要求简短自然回答；仍允许用户明确要求详细内容。未用提前播放
   “收到”等固定语音冒充实际回答提速。

TLS 正常验证保持开启；会话恢复基于此前已经验证的同一平台会话。网络错误的
对应连接不保留，取消后关闭活连接并释放音频。有效的关闭句柄可能留到短 TTL
到期，它是有界缓存，不是仍在后台发送请求。

## 验证和限制

- 28 项 C11/ASan/UBSan 主机检查通过，包括新增请求合并的边界、尾块、错误长度、
  发送失败和取消；音频关闭固件也构建成功。5 项 USB 乱序回归通过。
- 最终固件六轮声学闭环全部完成，输入识别、灯控、颜色/名字记忆、TTS 和恢复
  监听正常。外部麦克风的回复段本地识别结果与预期对应，未检测到满幅采样。
  这是固定合成源验证，不是新的真人唤醒率或主观音质验收。
- 最终版 TTS 与麦克风音量检测并发 14.399 秒事务完成，没有 PCM 欠载或 ADC
  DMA 丢失。最低空闲堆 **49,696 字节（48.53 KiB）**，worker 最低栈余量
  **2,624 字节**。内存余量仍紧，后续功能要重新测量。
- ASR 等待取消通过；已有云任务随后只查询到 completed，没有再次提交。
  空闲、录音、播放取消后均恢复监听，包含模型重载/USB 轮询的恢复时间分别
  625/1547/1125 ms；明确关闭后保持关闭。
- 另外验证普通 USB 的流式/非流式 DeepSeek 路径、120 秒缓存到期回收和交付监听
  状态，原始结果保存在 cache-expiry/report.json。闲置回收 **4,552 字节**，恢复
  监听后空闲堆 **74,256 字节**；COM5 已释放。缓存没有无限累积。

第一版只增加连接复用、上传块和轮询调整，三对样本仅改善 1.6%，未视为达标；
保留 comparison-01.json 和原始录音。第一次启动测试工具时它仍硬编码旧固件版本，
在任何云请求前退出；已改为显式 --firmware 参数，失败记录也保留。

平台文档明确当前 ASR 是异步文件接口，TTS 为非流式模型。因此这版仍不能达到
实时通话的接话速度。要进一步接近几秒接话，主要需要支持实时语音识别的服务接口；
已有流式扩展契约保留，正常运行仍由设备独立完成。
