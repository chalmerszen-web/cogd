等待完整转写与采集成功后确认。改口或取消撤销旧候选，硬件工具仍在最终

仍参与确认。本轮没有放宽这项规则，也没有修改VAD或ASR阈值。

测试采用同一条“请用一句话介绍你自己”，普通话／粤语／普通话唤醒，

## 内存实验及退出决定

候选发送原先在栈上复制最多2056字节WebSocket帧。188为候选专用发送增加
8字节可写前缀，在原TX缓冲内加掩码，一次TLS写入后恢复原始载荷。
保留2048字节TX／6144字节RX上限及原BUSY、部分写入、取消语义；没有SDK修改。

实际RISC-V反汇编显示，发送函数自身栈帧2096→48字节，但整个候选任务的
最低剩余栈是2360／2432／2432字节，没有达到预设3072字节门槛。
因此未执行6144→4608字节缩栈，也未执行第二组三轮。网络握手及其他调用
仍决定整个任务的栈需求，函数局部节省不等于可释放RAM。

此外，64位主机布局需要保持原对齐断言：188工作区前缀17024→17040字节，
C3结构16576→16592字节；应用1497088→1497424字节。没有证明可释放内存，
所以不保留这项额外接口和容量成本，实验源码留在冻结包中。

16项ASan／UBSan主机测试通过，覆盖帧边界和10000个随机帧、载荷恢复、
忙／取消／部分写入、连接所有者隔离、候选撤销及生命周期。
正常与关闭音频构建通过。保留三种初始失败：主机布局断言、WSL命令管道引用、
新测试提前注册idle钩子干扰旧首次注册场景；分别按完整对齐、独立脚本引用、
测试顺序修正，不弱化断言。回退后相同16项测试及两种构建再次通过。

本组三轮SDK最低堆57020字节，网络任务余栈3136字节，未观察到WDT、panic、
重启、DMA丢失或流播放欠载。它仅支持本组稳定性，不能覆盖其他输入曾出现
的低堆／截断问题，也不能与不同输入的旧结果当作受控A/B内存比较。
