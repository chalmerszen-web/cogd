## 主机复现

测试直接编译项目所用ESP-IDF的完整、未修改`transport_ws.c`及公开头文件，
只替换底层传输读写为可控制的字节源。它不是TLS或真实网络的仿真，也不访问凭据。
SDK提交`fff9895c82d744c7237be8847347bdd1b07c6643`，该源文件SHA256：
`57c4465ddbefdda3263ca4ee9302bc1d7269d7d78148b57f0c1dfe720c50620f`。

| 情况 | 原SDK读取行为 | 现有C11增量读取器 |
|---|---|---|
| 2/4/10字节帧头，13个中途超时位置 | 返回-1，帧头读取不能延续 | 全部保留进度并还原原文 |
| 125字节Ping仅先到7字节 | 自动控制帧路径返回-1 | 完整收齐后才交付 |
| 普通数据负载中途超时 | 保留剩余长度，可继续 | 可继续 |
| HTTP升级缓冲含WebSocket前缀 | 129种前缀均不丢字节 | 移交前仍由SDK读完 |

以上测试同时覆盖静态和动态SDK升级缓冲；原SDK源码未改。49项ASan/UBSan
测试通过，包括实时会话、取消、语音流、旧工具和新增的两个SDK目标。
证据在`artifacts/voice-fast/probe-ws-sdk[-dynamic]-01171-01.json`及
`test-ws-sdk-host-01171-02.log`。可按以下方式复现主机测试：

```sh
cmake -S host_tests -B artifacts/voice-fast/host-handoff-agent \
  -DAGENT_IDF_SOURCE="$PWD/.toolchains/esp-idf"
cmake --build artifacts/voice-fast/host-handoff-agent -j2
ctest --test-dir artifacts/voice-fast/host-handoff-agent --output-on-failure
```

`AGENT_IDF_SOURCE`为可选项；不提供时，原有可移植主机测试不依赖IDF。

## 有限实机计划

计划已冻结在`ws-reader-trial-plan-01171-01.json`：记忆操作和简单问候两组，
每组普通话/粤语/普通话连续唤醒，轮间不重启voice。要求6次首次唤醒、完整
输入和任务全部成功，DMA/重启为0，启动以来最低堆至少38532B。任一组失败，
完成并保留该组三轮后停止，不补刷通过，回滚68应用及本轮源码/配置。
每次烧录先完整备份并验证4MiB Flash，只写应用并核对非应用区域。

这只是保留候选的门槛；一秒内正式回答和48KiB余量仍需另行验证。
