## 已证实的差异

原 E/L 两支各有 127 帧感受野，联合分支再次使用 127 帧；有效原始感受野可达 253 帧。原训练按 256 帧裁剪完整录音，重新计算冻结特征并清空神经历史。原来针对单支骨干的“第 131 帧后与完整流一致”证明，不能覆盖后加的联合网络。

UX336 固定同一 checkpoint，检查 75 个既存失败窗口。33 个观测裁剪中 22 个隐藏表示不同，11 个关键裁剪在重置时没有支持唤醒的分数，连续流却有。提供完整骨干表示及 126 帧辅助左历史后，与保存的完整 F64 头逐值一致。训练模式 BN 还会压低部分分数，但这个固定末批对照不能单独证明 BN 是全部旧误触的原因。
