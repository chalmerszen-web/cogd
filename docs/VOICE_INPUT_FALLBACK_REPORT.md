同一个本地 ASR 对源音频和三份外部输入裁剪均转写为“改成绿色”，对板上完整录音和末尾三秒均转写为“改成黑色”。这将调查范围缩向采集/音频输入路径；尚不能确认模拟噪声、软件处理或识别模型中的具体原因，也不构成人工听觉真值。第三轮原完整来源匹配失败，声学延迟仍为 unknown，没有用两秒前缀诊断提升原验收结果。
