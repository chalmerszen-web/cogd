## 改动与边界

0.11.101-candidate-tls 保留 UX70 的分阶段工作区、完整输入校验和最终 ASR
之后额外等待 500 ms 的规则。只调整候选连接：握手保持工作线程优先级2，
不再临时升到4抢占优先级3的输入上传；ASR、常规 Omni 和 TTS 保持原规则。
候选继续独占 primary WSS，不能借此绕过连接互斥。

同时撤销工作区切换时无条件清除 TLS 票据的行为。票据独立分配，不引用
工作区，仍受固定服务端、60秒寿命和凭据变更失效约束。保留对象不能证明
服务端接受会话恢复。本轮同时改变这两点，不能分别归因或计算因果提升率。
