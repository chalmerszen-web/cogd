## 使用与后续边界

双击项目根目录 `打开设备对话.cmd` 后，可直接输入文字；`agent help` 查看命令。`agent voice on` 开启现有实验语音监听，仍存在误唤醒/漏唤醒；`agent voice off` 关闭。设备当前关闭自动语音，用户可先验证 Agent 业务和硬件工具。
