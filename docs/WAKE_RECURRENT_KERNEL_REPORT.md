# 序列声学表示的 C11 内核验证（UX475）

2026-10-04。**新推理内核的数值和编译资源检查通过；尚未训练、在设备上运行或替换唤醒模型。误唤醒和完整语音目标仍未完成。**

## 为什么新增这一表示

UX474 对已保存普通话近词/正确词的闭式检查证明，保持原两票和 256 ms 规则时，只提高两路阈值不能分开这一对。因此本次新增一层 32 状态 GRU，保留输入的先后变化，作为后续声学模型的候选表示。它是否能区分词尾，仍须经过训练与固定正负资料检验，不能由网络名称或单元测试推断。

采用 PyTorch 2.6.0 的 reset-after 约定：r/z/n 顺序，候选状态的 recurrent n bias 也由 reset gate 相乘，输入 n bias 保持独立。依据 [固定版本官方源码](https://github.com/pytorch/pytorch/blob/v2.6.0/torch/nn/modules/rnn.py)，并对本机 `2.6.0+cpu` 实际代码和 gate/bias 行为另做核对。实现为自有 C11，没有引入通用模型解释器或 C++ 运行库。

## 固定接口与范围

输入使用已有 40 维归一化 INT8 特征、实值比例 1/32；权重是 INT8 Q8，bias 是 INT16 Q8，隐藏状态是有符号 Q15。每个 16 ms 特征帧产生两个 Q8 logits：无完整唤醒事件、完整双语唤醒事件。该内核没有检测器、训练资格标志或动作权限，不能直接驱动业务。

513 个 sigmoid 查表点覆盖 -16..16、间隔 1/16，按 Q8 输入线性插值。生成器使用 80 位 Decimal 精度，设备只有整数运算；中间值采用 INT32、对称最近舍入且半值远离零。包括 INT8_MIN 在内的输入积累、循环积累、reset 乘积和 Q15 状态更新均有明确 INT32 范围。32 个新状态先写独立 scratch，再整体替换旧状态，避免按行更新污染后续 recurrent dot。

模型 7170 个参数，对应 6976 B 权重及 388 B bias，结构共 7364 B。状态与 scratch 分别 64 B。无新增堆分配；所有实例内存由调用方提供，查表只读。空参数或缓冲区相互覆盖在修改状态之前拒绝；reset 明确清除状态。

## 验证结果

| 检查 | 实际结果 |
|---|---|
| 严格 C11、ASan/UBSan | 通过 |
| 原生独立 INT64 参考 | 2056 帧、65792 个隐藏值、4112 个 logits 全部一致 |
| NumPy INT64 矩阵参考与实际 C 库 | 1024 帧、32768 个隐藏值、2048 个 logits 全部一致 |
| PyTorch 参数布局、batch/分块、bias reset 位置、梯度、导出拒绝 | 4 项测试通过 |
| 随机模型/初态、满范围输入和 bias、状态哨兵、空参数/别名、reset | 通过 |
| 固定 Q8 导出 | 超范围或非有限参数拒绝，没有静默夹权重 |
| C3 编译 ABI | rv32imc_zicsr_zifencei / ilp32，C11，通过 |
| C3 对象的内核代码及查表 | 2086 B，data/BSS 0 |
| C3 模型/state/scratch 结构 | 7364/64/64 B |
| C3 自有函数调用链峰值栈 | 128 B，门槛 192 B，通过 |
| 未解析符号 | 仅 memcpy/memset，无堆或浮点运行时符号 |

C3 数字来自当前 RISC-V 编译器的实际对象、静态断言、size/nm、stack-usage 与调用图，**不是板上执行、整固件体积或整个任务栈实测**。128 B 状态和 scratch 不包含 FFT、音频前端、采集任务或联网内存；此结果不能替代完整系统最低 48 KiB 堆验收。浮点 GRU 另核对低权重固定探针的近似误差，不把浮点与整数近似称为所有模型逐位等价。
