## 固定原声与设备对照

只调用已校验原 C 前端，不做神经推理。原归一化、40 个 Mel 带及 125 Hz 下沿保持，活动区间按原自动端点与原对齐位置定义。前端提取耗时 0.916 秒；唯一固定 pYIN 0.10.2 分析耗时 13.109 秒。配置为 16 kHz、1024 样本窗、160 样本步长、65–500 Hz、置信度 0.8、末 250 ms 至少 6 帧。90／160／240 Hz 控制的估计误差均低于 2%，静音没有可信音高。

设备归一化 INT8 饱和最大为普通话 0.6717%、粤语 0.3333%；原声可信音高低于 125 Hz 的帧占普通话 7.71%、粤语 2.42%。这些结果不支持将大量量化截断作为主要原因，也不能证明 CNN 没有保留音高，或将采集可靠性下降全部归因于 Mel 下沿。自动端点没有确定末字的音节边界，F0 也不能替代词面真值或作为重标依据。

ASan／UBSan、静音／直流／脉冲／极值／随机的五组独立整数参考，共 41035 样本通过；整块、随机分块及原地运行的输出和全状态一致。68 条冻结的完整输入因果滤波后没有截顶。没有 C3 计时或运行时内存实测，20 字节是原型结构大小。
