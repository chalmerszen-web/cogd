## 唯一五作业结果

输入主题为“现在灯是什么颜色”，最终为“现在灯是什么颜色？请简单回答。”；
revision改为“不用问灯了，请介绍你自己。”。音量80，测试窗口本机录音。

| 作业 | 候选输出/准备 | 结果 |
|---|---|---|
| pass | 嗯，现在灯是白色，我想想。 | protocol，正确拒绝未知白色状态 |
| revision | 嗯，现在灯，我想想。；已准备5120样本 | 改口后不播放旧候选，普通回答完成 |
| cancel | 嗯，灯的颜色，我想想。 | 校验未通过，缓存到上限；未发出取消测试 |
| failure | 嗯，现在灯是什么颜色，我想想。 | 主题超出既有长度，缓存到上限；未到注入点 |
| pass | 嗯，灯的颜色，我想想。 | protocol，拒绝原句中没有的“的” |

没有candidate_request_overlap/workspace_adopt，也没有候选播放事件。只有
revision触发prepared，且response_done=false/output_complete=false；其旧
候选在改口后退出，随后走正式回答。这证明改口屏障受测，不能替代其余分支。
五作业均正常归还资源，无灯光副作用、复位、WDT、panic或DMA丢失。
SDK最低堆47228B、网络栈2376B；完整请求重叠的资源门槛仍未验证。
