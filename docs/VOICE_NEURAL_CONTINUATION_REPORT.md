# UX147：用现有神经 VAD 检查弱续说

2026-09-29。本轮完成七份既有音频的有限离线对照。**没有证据支持把现有TEN模型直接
改作快速路径的续说检测，也没有开始新训练或烧录新固件。** 开发源码仍185，设备只读核实
为72-summary联网监听。完整输入、稳定一秒有效回答和全流程内存目标仍未完成。

上一轮证明了关键词转写可能在本地停录后才到达。本轮没有再增加关键词或延长等待，
而是检查项目已经具备的另一种分类器是否能补足弱音节证据。历史ADC衰减、降低能量门槛、
给WebRTC换滤波输入等失败记录先行核对，没有把这些方法重新当作新实验。

## 固定方法

编译当前`components/agent_vad`的真实C适配器、内核、厂商源码和权重，复用
`sources.cmake`与`sources.lock.cmake`逐文件校验。保留原定点DSP、INT8权重和窄整数等
构建定义；WSL GCC13.3.0、C11、关闭FMA收缩、ASan/UBSan出错立即停止。

输入是UX142三份完整8秒PDM关闭录音，加两份旧短问候、background-tail和数字静音。
所有WAV哈希与原清单一致，16kHz单声道PCM16，整段按256样本/16ms送入，每段只初始化一次。
不裁切、不增益、不滤波、不重采样、不在末尾补静音。两份短控制末尾128/192个样本不足
一帧，明确未评分；没有把它们丢弃成不存在。共2627完整帧、42.032秒已评分PCM。

沿用原适配器0.4概率门槛；记录整数Q15后以ceil(0.4×32768)=13108比较，没有扫描阈值。
区域沿用之前的诊断区间。它们不是人工逐帧语音标注，不能据此计算准确率、召回率或F1。

## 结果与限制

| 录音 | 3000–3240ms弱续说诊断区间超过0.4的帧 | 7000–8000ms尾段超过0.4的帧 |
| --- | ---: | ---: |
| UX142第一段 | 7/15 | 0/63 |
| UX142第二段 | 1/15 | 0/63 |
| UX142第三段 | 0/15 | 0/63 |

后两段正是原端点会在3300/3240ms截断的完整录音。神经模型能在它们后续4000–4200ms、
5000–5760ms的一些区间给出较高分，但在关键续说处并未持续提供替代证据。
这不足以支持把新分类结果直接接入结束判定，因此没有执行条件性的端点候选重放或部署。

第三段3000–3240ms的最高分为10034/32768≈0.306；旧RF18录音5888–6888ms尾段的
中位分为10393/32768≈0.317。仅就这两个固定诊断区间，降低单一概率门槛会同时接纳
相当一部分旧尾声，不能由此推断能兼顾弱音和噪声。没有按这几个样本调阈值或训练模型。

数字静音250帧全部低于0.4，background-tail共7/250帧超过门槛，两份问候分别123/430、
120/197帧超过门槛。这些是分类输出计数，不是正确/错误次数；尤其问候的末秒可能包含
真实语音，未把它整段标作静音，也未用这些数字声称真人泛化通过。

全部七次运行无ASan/UBSan报告，初始化后的分配计数不变、关闭后分配归零。
本机模型分配40772B。**这是x86原生进程值，不是C3 RAM实测**；本机使用原生单精度运算，
没有运行C3的RVfplib汇编，不能声称与设备逐位相同或把电脑运行时间作为C3性能。
历史同板TEN神经部分CPU峰值23.428ms，而当前hop为16ms；它本来就不能不加证明地承担
整段实时续说。更换检测器还必须解决实机计算、调度和并发内存，不能只看离线分数。

新运行器首次构建因误用不存在的`AGENT_ERR_IO`枚举失败，只把辅助程序改成现有
`AGENT_ERR_STORAGE`后通过；错误日志保留。生产适配器、模型、前处理及端点未改。
所有脚本、原始逐帧CSV、统计、输入哈希及构建日志位于
`artifacts/voice-fast/neural-continuation-ux147/`。

结束前只读查询COM5时，第一次遇到已排队的语音任务`@error timeout`，其后同一原始日志
已包含正常status JSON。保留第一次失败，再先保存并排空已有异步消息后重新只读查询。
没有把超时当作成功，也没有隐藏设备故障：已有监听在本轮期间产生过一次未经脚本触发的
录音/联网任务，触发来源未知。本轮七次离线推理本身没有云请求，测试脚本没有播放音频、
发起录音、设置Wi-Fi、烧录或改变语音模式。

后一次查询确认72-summary、Wi-Fi在线、fast/capture/listening、reuse ON、prefetch OFF、
灯关闭。上下文仍1179事件/987692B、generation17、next_record4277，与UX146恢复后持久
字段相同；2MiB上下文、204800B历史预算、448KiB录音槽、分区和默认安装包未改变。
串口查询已退出。原失败模型路线保留为证据，不冒充新的固件改进。

是否影响模拟麦克风。此前收音关闭PDM、强信号下降低Wi-Fi发射功率已经启用，不能重复宣称
