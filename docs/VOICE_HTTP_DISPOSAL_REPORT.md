# UX444：完成的 HTTP 句柄在 TTS 收尾前释放

2026-10-03。唯一三轮正常语音实验已结束，恢复原 `0.11.72-summary`。本次最低堆通过，但提前应答与延迟未通过，实验选项保持默认关闭。**现场误唤醒仍未修复。**

## 实现与所有权验证

新增可选 `AGENT_VOICE_HTTP_FORGET`，依赖 `AGENT_VOICE_HTTP_RELEASE`。最终 LLM 网络生产者返回后，若语音流仍活动，则调用已有 `esp_agent_http_forget()`，销毁已经完成的 HTTP 客户端，然后等待 TTS 播放结束。普通进度应答继续使用 `esp_agent_voice_stream_end()`，不会关闭仍由请求生产者使用的 HTTP。工具续轮、中间请求和 ASR／TTS WebSocket 复用保持。

代价是最终 HTTP 客户端中跨轮 TLS 会话票据丢失；不能假定下一轮建连更快。没有更改任务栈、TLS 发送／接收预算、唤醒模型、阈值、判定窗口、VAD、上下文分区或历史预算。

四项受影响的主机 ASan／UBSan 检查通过：语音流所有权、最终 socket 释放、最终完整客户端销毁、HTTP 会话所有权。覆盖生产者退出前不释放、普通进度不释放、取消及重复收尾不重复销毁。原编译选项保持默认 OFF。

正常 C3 单次构建为 1,533,120 B，距工程预算 1,540,096 B 余 6,976 B。原冻结脚本只接受未优化的 `esp_agent_voice_stream_end` 名称，实际 GCC 链接生成 `.isra.0` 克隆，导致验证停止。原脚本及失败记录保留；r1 只核对同一 ELF 中 `jal esp_agent_http_forget` 后 `j esp_agent_voice_stream_end.isra.0` 的顺序，不重建、不改固件或验收门槛。

与 UX309 冻结来源核对：529 个原非 Markdown 文件一致，另外五个是已声明的可选策略、版本分支及主机用例改动。SDK 配置及三个唤醒模型一致，所有探针关闭。不能继续声称本轮所有 534 个原文件完全不变。

## 唯一三轮实测

公开普通话、粤语、普通话唤醒素材，每轮只有一次唤醒尝试；后两轮在上一轮完成后约 265／281 ms 发起，未等待 ready，未逐轮查询或导出录音。完整输入均为“请记住，我给这盏灯取名叫小星星”。只运行这一组，没有补跑失败轮。

| 指标 | 结果 |
| --- | --- |
| 首次唤醒／完整识别／记忆任务 | 均 3／3 |
| 运行异常、看门狗、复位 | 均 0 |
| 话题相关提前应答 | 2／3，未通过全部三轮要求 |
| 第三轮提前应答 | 候选传输返回 network，回退“收到我来处理” |
| 最终回答 | 三轮均“记住了，这盏灯就叫小星星” |
| SDK 累计最低空闲堆 | 49,204 B；高于 49,152 B 门槛仅 52 B |
| 观测最大连续块最低值 | 38,912 B，通过 24,576 B 门槛 |
| main／NET／TTS／音频剩余栈 | 2,304／1,844／2,264／752 B，未调整 |
| 自然误唤醒率 | 本阶段未测，不能声明改善 |

UX309 最低堆 47,856 B；本轮多 1,348 B。这是不同运行的描述性差额，不能全部归因于句柄释放，也不能把仅 52 B 余量推广为长期稳定性证明。

外部麦克风实录的三个输入波形均通过原匹配门槛，本地独立 ASR 确认最终回答。距输入有效声音结束的 10 ms 能量起声候选如下；这些候选不是人工首音素标注，不记为一秒验收通过。

| 轮次 | 提前应答候选 | 最终回答候选 |
| --- | ---: | ---: |
| 普通话 1 | 5.045 s | 9.335 s |
| 粤语 2 | 2.753 s | 7.273 s |
| 普通话 3 | 3.101 s，通用回退 | 5.601 s |

提示音与通用回退不替代有效回复，第三轮失败保留。没有根据本轮另选缓冲大小、减栈或补一组结果。
