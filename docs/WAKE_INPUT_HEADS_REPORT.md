2026-10-04。**误唤醒尚未修复；诊断应用已撤回，设备恢复原 `0.11.72-summary`。** 自动唤醒、自动语音关闭，Wi-Fi 在线，USB 文本交互可用。关闭监听只是临时避免误触，不能算识别效果改善。

## 做了什么

此前 UX470 同板对照中，辅助声学模型拦住了一条粤语近似词，却新增一条普通话近似词，负例总数仍是 1/10。因此本次只补齐观测证据，没有调阈值、换模型、训练或继续重复业务组。

诊断协议 `pcm=2` 在既有两路平滑分数之外返回三路原始模型输出，并记录每个 512 样本块实际传给推理器的 `armed` 值。仅在 `AGENT_KEYWORD_PCM` 构建启用；判定数学、冻结模型、初始状态、门槛 740、增益 1、SDK 和分区保持原样。元数据不新增堆分配，仍借用既有空闲请求工作区；不增加常驻 PCM 或任务。C3 帧结构 1072 B，较原帧增加 8 B；输入元数据结构仍为 24 B。

正常应用预算内只构建一次：应用 **1537072 B / 1540096 B**，剩 **3024 B**。三个关键编译单元的最后一个 `-std=` 都为 `c11`。应用 SHA256 为 `3ef1267b2862b62d56367e7661ba76d5de3f798b52dd6ee0ad7f3bcc5481b18f`。队列发布、取消、并发、CRC 和新增元数据通过 C11 ASan/UBSan；初次 PowerShell 参数解析失败及未启动测试记录保留，不能算一次成功测试。

COM5 同一设备仅回放四条事先选定的开发声音，每条一次、188 块、6.016 秒。观测模式不播放提示、不录入 Flash、不执行对话或工具。共取回 **752 块 / 24.064 秒**原始 PCM，全部序号、CRC 和采样时钟通过，无队列丢失、满幅样本、DMA 丢失或复位。原模型 C 实现按每块实测 `armed` 重放，三路原始输出、两路平滑输出和事件 **752/752 完全一致**。最大记录推理耗时 14342 µs，小于 32 ms；这不是完整联网对话的堆或速度验收。

## 发现与限制

普通话 `sapi-kangkang-08` 的源文本为“你好小燕”。固定 RMS 包络对齐相关系数 0.656，事件位于原声源范围内，`armed=true`。辅助头此前原始峰值为 Q8 1026；两票支持被既有 256 ms 事件匹配窗口保留，在原候选命中时完成确认。因此这条误触不是本次数据传输或设备/主机数值差异造成的。源文本不等于已获真人确认的实际音素，不能把所有现场背景误触归为这一原因。

同声音正确词 `sapi-kangkang-03` 的精确重放也使用了较早的辅助支持：触发瞬间辅助平滑分数分别为 -56（近词）和 17（正确词）。只要求触发瞬间高分或任意缩短窗口，会同时影响正确词；本次没有据此扫参、修改规则或声称修复。

第二条粤语近词的对齐相关系数 0.487，但事件在对齐后的原 WAV 末尾之后 **721 样本 / 45.0625 ms**，未通过本次原定的“事件位于声源 WAV 内”检查。保留失败并停止后续来源归因，未改门槛或换对齐方法迎合结果。该时间差也不能直接证明控制器有错误；识别器可能延后确认。后两条仍有完整 PCM 与数值一致性证据，但本次不报告它们的声源归因通过。首次辅助脚本对负例空能量端点的格式化异常，以及修正格式化后这一断言失败，均保留在原日志中。

这些材料是已揭盲的合成开发声音，不是真人双语盲测、安静误报或每小时误唤醒验收。另核对后续 CTC 方案的数据准备代码，已知近词使用完整前缀及负尾标签，不能将它的失败误归为“所有负例只训练 OTHER”；这不是当前已装声学模型的训练规则。目前尚无通过实机对照的修复版本。UX277 延迟、UX469 内存/一秒响应及 UX470 声学失败继续保留。
