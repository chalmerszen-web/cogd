## 构建时选择通信方式

在 P4 项目目录执行：

```powershell
./tools/build.ps1 -CommunicationMode AOQ -AoqProbe -BuildDir build-aoq-native
```

`-CommunicationMode AOQ` 编译原生 AOQ，版本标为 `0.10.0-p4-aoq-dev`；`WSS` 保留原有通信方式，且是默认值。对应宏为 `COGD_COMM_MODE=COGD_COMM_AOQ` 或 `COGD_COMM_WSS`。切换传输需要重新构建、安装固件；串口的 `voice mode` 不会改变这个宏。

C3 保留原有构建及通信路径，不加入 P4/AOQ/QUIC 依赖。AOQ 未为 C3 实现；兼容指同一架构仍可构建运行原有 C3 程序。

## 正常语音对话

串口逐行发送，等待每条命令返回：

```text
agent voice off
agent voice mode natural
agent voice on
```

说“你好小智”，提示音后提问。这个入口使用共享的 COGD 对话流程，包含历史、工具和拍题状态；在 AOQ 固件中使用原生 AOQ，在 WSS 固件中使用原有 WSS。答完后可直接继续追问。功能接入不等于所有回归已通过，验收仍需看设备状态和实际画面。

AOQ 源码默认 600 毫秒声学断句、阈值 0.5。关闭语音后可用 `agent voice endpoint 400` 临时比较；这不是持久设置，也不是已经接受的默认值。测试中应保持配置不变，使用同一问句，并检查完整转写、回答、提示音和实际等待感。

## 连续摄像头问答

以下功能已装入当前候选，连续视频流程尚待实测：

```text
agent voice off
agent voice mode natural
agent voice video on
agent voice on
```

这一路使用千问 Omni，发送 P4 麦克风声音及当前板载摄像头 JPEG，返回文字和语音。图像为 320×256、最多每秒一帧；程序等待云端检测到语音后才发视频，并检查画面时间和相机归属。拍题工具接管镜头后，旧视频采集会停止，不夺回新照片的显示区域。

恢复纯语音时，关闭语音，执行 `agent voice video off`，再开启语音。纯语音和视频使用不同模型及断句配置，不能直接用两道不同问题比较传输速度。细小题目仍使用完整分辨率拍题接口；该视觉工具和其他原有 HTTP 工具保留原协议。

## 独立 ASR、TTS

`classic` 模式接入原生独立 ASR/TTS，通用适配器的固定输入和播放已通过实板验证，完整麦克风流程仍待验证。独立 ASR 按千问协议通过可靠 QUIC Data 对象传音频，TTS 从 Audio 通道收 PCM；正常实时对话的麦克风音频使用 QUIC DATAGRAM。原有文本模型请求仍走 HTTP。

AOQ 固件不会悄悄回退 WSS。原有 `fast` 引擎保留在 WSS 构建；AOQ 构建明确拒绝选择 `fast`。

固定内容互通诊断仍可单独运行：关闭语音，执行 `agent aoq tts probe`，保存返回的整数 `generation`，再运行：

```text
agent aoq tts play <generation>
agent aoq asr probe <generation>
```

P4 播放并重采样同一份“原生语音测试成功。”音频，再直连独立 ASR 检查文字。这是固定输入诊断；它的通过不能替代新通用适配器或实际麦克风的验证。

新候选另有 `agent aoq speech asr <generation>`，用同一份固定音频测试 `classic` 实际使用的通用 ASR 路径；需检查返回文字完整，不能只看任务结束。`agent voice say TEXT` 则测试通用 TTS 路径。

## 单轮诊断与状态查询

`-AoqProbe` 额外启用 `aoq-test`、`aoq-video-test`。它们仅用于一轮简短问答，下一问需重新唤醒，不承载正常连续追问、历史、打断或辅导流程。切回 `natural` 才是共享的完整对话入口。

`agent voice status` 查看模式，`agent voice realtime` 查看正常对话配置和时序，`agent aoq live result` 读取单轮诊断的上次回执。`agent cancel` 可取消当前任务。

测速分别记录说话结束、云端断句、首段回复音频到达和扬声器开始。仅有提示音、正确答案或链路互通，都不能单独证明后半句完整或响应比 WSS 更快。
