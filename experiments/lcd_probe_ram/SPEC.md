# LCD 黑屏隔离实验

2026-10-10：用户反馈 0.12.1-clock 屏幕没有时钟，实物验收为 FAIL。

本实验复用已验证的 C3 RAM 启动和 USB 通道，使用固定 GPIO4 MOSI、GPIO5 SCLK、GPIO10 DC，直接用 GPIO 发送参考 BSP 的初始化和 RGB565 数据。输出全白 3 秒，再输出红/绿/蓝/白四色条；主机等待 60 秒观察，随后核验完整 Flash 并恢复原应用。该程序没有 Flash 写入、联网、音频或身体接口操作，也不推断未知背光和复位脚。

编译使用 experiments/lcd_probe_ram/build.py，运行使用 run.py；采用项目 ESP-IDF Python 环境。镜像须通过未定义符号、IRAM/DRAM 地址边界和启动向量检查。使用前重新读取并校验完整 4 MiB Flash。USB 回传引脚低/高电平读回和绘图阶段，只能证明 MCU 端状态；四色条是否出现在实物屏幕必须另行记录。

证据在 artifacts/clock-20261010/lcd-probe-run/。本次 GPIO 低电平 0x00000000、高电平 0x00000430，Flash 前后逐字节相同，恢复 0.12.1-clock。用户反馈“屏幕有亮光，但没有色带”，实物 FAIL。该初版引脚自检额外产生一次 SCLK 上升沿，不能据此排除字节错位。

## 后续八种字节对齐测试

phase_probe.c 复用基础发送/初始化函数，首次使能前预置输出低，不做 SCLK 高低自检；每次 N 命令增加一个额外脉冲，总共 8 种相对位边界。每次初始化后填满 162×132 GRAM，避免只写到不可见窗口。run_phase.py 将 USB 绘图完成事件与随后新鲜的摄像头照片绑定，不修改图像。

2026-10-10：8 张原始照片均未出现四色条；完整 Flash 前后相同，恢复 0.12.2-clock。证据 artifacts/clock-20261010/lcd-phase-run/。这降低了单纯字节错位/窗口偏移的可能性，但没有示波器、屏端接线及实际芯片身份验证，不能把结果写为“屏幕已损坏”。
