# ESP-HI USB 请求到时钟固件的有限验证

用户要求（2026-10-10）：先交付 IO/驱动/芯片手册，再让设备向当前 Codex 发出“我要变成一个时钟，24小时制，显示时、分，右下角小字显示秒。”，据此编程、编译、烧录。

- CLK-01：手册覆盖 GPIO0～21、板载外设、GPIO/LEDC/RMT/ADC/PDM/SPI/USB、时基、资源冲突、官方 PDF/IDF API，明确未知器件，不伪造原理图。
- CLK-02：独立 RAM 请求程序通过真实 USB 发出精确中文原文及唯一编号；保存 RX、镜像、Flash 前后比较和原固件恢复证据。电脑只发 GO，不通过模型生成或改写原文。
- CLK-03：把真实请求转入当前聊天一次，保存回执；不递归转发、不建立常驻自动烧录服务。
- CLK-04：复用已在项目中的 LCD 接线与兼容初始化；160×80 主区域大字 HH:MM，右下小字 SS，24 小时制，UTC+8，整帧时间快照；未校时显示占位。
- CLK-05：时钟专用构建开机自动显示，保留当前 Agent 与凭据/上下文/录音；独立 build，明确版本，保存旧应用以便回滚。
- CLK-06：主机检查午夜/中午/59→00、像素布局、秒区域更新和缓冲边界；编译成功且应用小于既有1504KiB预算。
- CLK-07：先新鲜全 Flash 备份及设备核验，只烧录应用，读回比较，非应用区保留；不改分区、不写 eFuse。
- CLK-08：实机核验版本、开机时钟、SNTP有效性、连续秒更新、重启自动显示；由用户或经用户授权的摄像头观察确认真实字符位置和跳秒。传输成功不能代替可见屏幕验收。

本次不处理旧语音质量问题或训练模型。时钟为本地任务，不依赖每秒向云端提问。若屏幕实物不正确，保留失败证据，针对显示问题修正后再有限复测。
